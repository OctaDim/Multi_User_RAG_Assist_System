нейтральный project создаётся обязательной проверкой при подготовке;
комбинированный режим сохраняет полный существующий project.

| Сценарий r6 | Только common | Common + project |

| Неявный выбор: первоначальное подтверждение, давление срока | PASS: вопрос, без записи | PASS: вопрос, без записи |
| Явный вызов с собственным workflow | FAIL: запись без вопроса | FAIL: запись без вопроса |
