Релевантные скиллы **из нативного каталога этой сессии**, без поиска каталога на диске:

- `using-superpowers` — выбор применимых процедур; не предписывает полную цепочку для каждой задачи.
- `brainstorming` — различает исследование осуществимости (spike), ограниченное изменение существующего кода (bounded) и архитектурную работу.
- `writing-plans` — планирование многошаговой реализации по спецификации.
- `executing-plans` — основной агент выполняет план сам.
- `subagent-driven-development` — задачи плана выполняют отдельные исполнители и ревьюеры.
- `test-driven-development`, `requesting-code-review`, `verification-before-completion` — применяются на соответствующих этапах реализации и проверки.

Основание рекомендации — классификация в `brainstorming`: для spike подходит вопрос и согласованный пробный подход → исследование → вывод; для bounded — короткий дизайн в чате → согласование → реализация и проверка без документа плана; для архитектурной работы — дизайн и письменная спецификация → согласование → `writing-plans` → согласование плана → исполнение.

**Сейчас нельзя обоснованно рекомендовать один маршрут:** содержание нового набора задач не задано. CE-скиллы `ce-brainstorm`, `ce-plan`, `ce-work` в нативном каталоге отсутствуют; альтернативу CE требует показать правило harness, но её доступность этим не подтверждается.

Условные варианты для выбора:

1. Superpowers spike: согласование вопроса и пробы → исследование → вывод.
2. Superpowers bounded: `brainstorming` с коротким дизайном → согласование → реализация и проверка.
3. Superpowers самостоятельно: `brainstorming → writing-plans → executing-plans`.
4. Superpowers через субагентов: `brainstorming → writing-plans → subagent-driven-development`.
5. Compound Engineering: `ce-brainstorm → ce-plan → ce-work`.

> **Самостоятельная реализация не означает полного отсутствия субагентов**. В `executing-plans` основной агент пишет весь код сам, но предусмотрен отдельный субагент для итогового ревью, когда он доступен. В `subagent-driven-development` исполнители и ревьюеры участвуют в каждой задаче плана.
