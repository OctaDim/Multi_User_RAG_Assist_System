# Статичный пользовательский вход и память в harness

Принято: 2026-10-04. Область: общая архитектура harness.

Пользователь выбрал общий вход AGENTS.md и минимальный мост CLAUDE.md вместо одного AGENTS.md для обоих инструментов. Дополнительная прямая директива: входная настройка принадлежит пользователю; агентское состояние и накопленные знания развиваются внутри harness.

Причина разделения: накопление опыта не должно переписывать основу, с которой пользователь запускает агентов. Конкретный контракт и разрешённые действия находятся только в [правиле](../rules/comm-user-owned-entrypoints.md).

Уточнение пользователя о ссылке допускает документированный относительный импорт корневого файла. [Claude Code описывает импорт через @path](https://code.claude.com/docs/en/memory#share-one-file-with-other-coding-tools); путь разрешается относительно файла, содержащего импорт. Сам мост не служит местом хранения дополнительных инструкций.

Название категории передачи задач уточнено пользователем: handoffs/. Прежнее название handoff/ заменено в обоих пакетах, индексах и активных пояснениях. Ранее созданные отчёты о проверке прежнего каркаса являются историческими свидетельствами, а не текущей схемой.

Уточнение пользователя 2026-10-05: разрешены создание статичных AGENTS.md/CLAUDE.md и автоматическое восстановление стартовых ссылок. Это узкое исключение из прежнего запрета, а не разрешение хранить там состояние сессий или переписывать другие настройки. Объём исключения определяет [правило проверки](../rules/comm-entrypoint-links-rule.md).

Уточнение пользователя 2026-10-05: прямое редактирование обоих входов запрещено также
пользователям; изменения только через согласованную обработку inbox. Прежние советы
владельцу исправлять файл вручную или через UI отменены. Выбран вариант 1: переносимые
проверки с предупреждением при обнаружении правок и блокировкой проверяемого коммита.
Запись редактором не блокируется. Перед восстановлением стартовых ссылок показывается
сообщение о повреждении и предстоящем восстановлении. Применение выбранного механизма
описано в [инструкции подключения](../skills/comm-diagnose-harness-entrypoints/references/entrypoints.md).

Последующее уточнение пользователя 2026-10-05 отменяет вариант с Git hook: harness должен
работать без дополнительных индивидуальных настроек машины. Действует предупреждающая
проверка: «Прямое редактирование AGENTS.md и CLAUDE.md запрещено договорённостью harness,
но технически не заблокировано». Пользователь отдельно подтвердил эту формулировку.
Hook удалён; блокирующая проверка, обязательный Git и начальная регистрация отменены.
Сравнение с существующей историей Git необязательно; без истории неизменность произвольных
настроек не доказана. Правила inbox и уведомление перед восстановлением ссылок сохранены.

Указатели на текущих владельцев обновлены 2026-10-08; даты и исторические
результаты выше не изменены этим переносом.
