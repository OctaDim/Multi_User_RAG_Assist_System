# Контейнер скиллов в историческом снимке

Папка объединяет установочные материалы скиллов прошлой редакции.

Пример: skills/example/SKILL.md показывает устройство установочной копии; пример иллюстративный.

Это человеческое пояснение, а не агентская инструкция. Исторический снимок и его результаты не подтверждают текущую версию harness.
