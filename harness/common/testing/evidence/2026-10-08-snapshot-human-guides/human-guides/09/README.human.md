# Правила в историческом снимке

Папка сохраняет машинные правила конкретной прошлой редакции для её проверки.

Пример: comm-example.md представляет правило той редакции; пример иллюстративный.

Это человеческое пояснение, а не агентская инструкция. Исторический снимок и его результаты не подтверждают текущую версию harness.
