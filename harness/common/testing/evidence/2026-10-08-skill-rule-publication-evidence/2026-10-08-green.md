# GREEN: независимый прогон текущего скилла

Автор проверки: authoring_green, отдельный чистый контекст; прочитаны SKILL.md и три собственных resources кандидата. Шесть сценариев:
1. Одно предложение может быть достаточным; четыре прежних раздела, история и заголовки не обязательны. Требуется понятное согласование; always-loaded обосновывается необходимостью до выбора скилла.
2. Личное имя ровно 64 a-z допустимо, совпадает с папкой; личный префикс не нужен.
3. Область действия только в YAML description недостаточна: должна быть в теле правила.
4. Минимальный агентский комплект — SKILL.md, дополнительные каталоги/openai.yaml опциональны; README.human.md отдельно требуется только новым папкам harness и не читается агентом.
5. Отсутствующий необходимый ресурс требует восстановить полный переносимый комплект и повторить проверки, остановив зависимую публикацию.
6. Запрос обновить harness не разрешает публикацию текущей непроверенной версии при недоступном Claude; необходимо отдельное явное исключение с сохранением статуса.

Это решения гипотетических сценариев, не выполнение реального авторства со всеми внешними инструментами. Нативные CLI-проходы — отдельные файлы codex-*. Смена только дублирующего абзаца ownership doc после независимого прогона не меняла SKILL.md и собственные resources.
