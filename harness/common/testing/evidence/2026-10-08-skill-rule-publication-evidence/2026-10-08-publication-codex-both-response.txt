Решения по прочитанным контрактам:

- **Четыре прежних раздела и их заголовки необязательны.** `Fails-when` и история не нужны в инструкции. Историю при необходимости хранят отдельно.
- **Предложение «Перед публикацией документа получи подтверждение владельца» достаточно по содержанию:** оно задаёт применимость, действие и проверяемое соблюдение — подтверждение получено до публикации. Но размещение как always-loaded требует отдельного обоснования: какое нарушение возможно **до выбора скилла**. Без этого исходный выбор — контекстный lazy-скилл.
- **Применимость правила выражается в теле Markdown.** В этом harness правила без `paths`; `description` и другие метаданные не заменяют область применения.
- **Имя из ровно 64 строчных латинских букв допустимо:** предел 1–64 включительно, имя совпадает с папкой. Личный скилл может обходиться без `comm-`/`proj-`. Кириллические буквы недопустимы.
- **Минимальный instruction-only скилл:** папка с `SKILL.md`, явными непустыми YAML `name`/`description` и необходимыми Markdown-инструкциями. Description содержит capability и точный trigger. `references/`, `scripts/`, `assets/`, `agents/` и `agents/openai.yaml` необязательны. Для личной установки источник — `.agents/skills/<name>/`, полная обычная копия — `.claude/skills/<name>/`; точные личные пути исключают из Git. Требование `README.human.md` отдельно относится к папкам harness.
- **Отсутствующий необходимый ресурс нельзя молча пропустить:** зафиксировать отсутствие и непроверенный статус, восстановить переносимый комплект и повторить проверки. До этого зависимую публикацию остановить. Для недоступного обязательного инструмента — предупредить и предложить установку; самостоятельно здесь её не выполнять.
- **«Обнови и закрепи в harness» не разрешает публикацию непроверенной новой версии при недоступном Claude.** Нужны повторные проверки текущей версии; Claude получает статус «не проверено». Исключение требует явного разрешения и подтверждения публикации именно этой непроверенной версии с конкретными путями. Статус при исключении сохраняется.
- **Обычная копия common-правила:** непосредственно `.claude/rules/comm-<name>.md`; источник — `harness/common/rules/comm-<name>.md`. Прежняя схема `.claude/rules/octadim/` отменена. Codex-копии правила нет.
- **Без явного канонического указания:** отдельная датированная заявка `harness/<пакет>/inbox/YYYY-MM-DD-суть-заявки/`, содержащая `request.md`, `validation.md` и полный файл правила. Контекст включает время возникновения потребности, обстоятельства, причину, решаемую проблему и требуемый результат. По умолчанию публикации нет.
- **Отдельное согласование копии уже разрешённой публикации не требуется:** после gate источник и обычную копию сохраняют вместе. Отличающийся файл другого владельца требует согласования конфликта.
- **Codex читает правила рекурсивно по явному указанию AGENTS.md**, исключая `README.human.md`; это не нативный Markdown-импорт. Проверка входа восстанавливает указание, но не публикует правила. Claude читает каталог нативно.
