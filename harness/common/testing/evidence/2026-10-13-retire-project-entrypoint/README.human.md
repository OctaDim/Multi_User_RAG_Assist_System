# Проверка вывода старого скрипта

Здесь находятся результаты сопоставления архивной обёртки и неизменённого общего скрипта. Например, characterization.json показывает код выхода и наличие безвредного маркера в каждом временном сценарии. Отрицательный результат эквивалентности не означает завершение заявки.
