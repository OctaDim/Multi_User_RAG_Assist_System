Условные варианты:

1. **Superpowers, через одного агента:** `brainstorming → writing-plans → executing-plans` — требует отсутствующих навыков.
2. **Superpowers, через субагентов:** `brainstorming → writing-plans → subagent-driven-development` — требует отсутствующих навыков.

> **Самостоятельная реализация не означает полного отсутствия субагентов**.
> В `executing-plans` основной агент пишет весь код сам, но скилл предусматривает отдельного субагента для итогового ревью, когда он доступен.
> В `subagent-driven-development` отдельные исполнители и ревьюеры участвуют в каждой задаче плана.

3. Согласование эксперимента → исследование → выводы.
4. `brainstorming` с коротким дизайном в чате → согласование → реализация и проверка.
5. `systematic-debugging` → установление первопричины → исправление и проверка — навык отсутствует.
6. **Superpowers + Compound Engineering:** `using-superpowers + ce-brainstorm → ce-plan → ce-work`  - с одновременным выполненим `using-superpowers и ce-`этапов
7. **Compound Engineering:**  `ce-brainstorm → ce-plan → ce-work`  - нативный ce-маршрут
8. Без специального маршрута — текущая модель c effort самостоятельно выполняет задачу.
