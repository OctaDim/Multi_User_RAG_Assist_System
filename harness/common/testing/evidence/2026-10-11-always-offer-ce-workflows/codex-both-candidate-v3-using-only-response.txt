В нативном каталоге доступны:
- `using-superpowers` — явно вызван и прочитан; конкретного маршрута для замены одной подписи не рекомендует.
- `brainstorming` — для согласования изменения.
- `ce-brainstorm`, `ce-plan`, `ce-work` — для маршрутов Compound Engineering.

`writing-plans`, `executing-plans`, `subagent-driven-development`, `systematic-debugging` в нативном каталоге отсутствуют. Поэтому следующие варианты Superpowers условные, а не установленные рекомендации:

1. Короткий: `brainstorming` с коротким дизайном в чате → согласование → реализация и проверка.
2. Исследовательский: согласование эксперимента → исследование → выводы.
3. Отладочный: `systematic-debugging` → установление первопричины → исправление и проверка.
4. **Superpowers, через одного агента:** `brainstorming → writing-plans → executing-plans`.
5. Superpowers, через субагентов: `brainstorming → writing-plans → subagent-driven-development`.

> **Самостоятельная реализация не означает полного отсутствия субагентов**.
> В `executing-plans` основной агент пишет весь код сам, но скилл предусматривает отдельного субагента для итогового ревью, когда он доступен.
> В `subagent-driven-development` отдельные исполнители и ревьюеры участвуют в каждой задаче плана.

Обязательные альтернативы:

6. **Superpowers + Compound Engineering:** `using-superpowers + ce-brainstorm → ce-plan → ce-work`  - с одновременным выполненим `using-superpowers и ce-`этапов
7. **Compound Engineering:**  `ce-brainstorm → ce-plan → ce-work`  - нативный ce-маршрут
8. Без специального маршрута — текущая модель c effort самостоятельно выполняет задачу.
