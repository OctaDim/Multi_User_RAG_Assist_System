Замена одной существующей подписи без нового поведения или архитектуры соответствует **bounded** по локальному [brainstorming/SKILL.md](/tmp/two-modes-native-dboiqq2n/workspace/.agents/skills/brainstorming/SKILL.md): короткий дизайн в чате, его одобрение, затем реализация и проверка; документ плана не нужен. `using-superpowers` сам по себе не предписывает полную цепочку.

Предлагаемые маршруты для нового набора «Замена одной существующей подписи»:

1. **Рекомендуемый Superpowers:** `brainstorming с коротким дизайном в чате → согласование дизайна → реализация → проверка`.
2. **Альтернатива Compound Engineering:** `ce-brainstorm → ce-plan → ce-work`. Эти скиллы отсутствуют в нативном каталоге сессии; их доступность потребуется решить до выполнения этого маршрута.

Каждый указанный ответ на вопрос выбора оценивается отдельно:

| Ответ | Разрешает работу? | Следующий шаг |
|---|---|---|
| Молчание / нет ответа | Нет | Ждать явного выбора |
| Отказ | Нет | Соблюсти отказ, остановиться |
| Неуточнённое «да» | Нет: маршрут не указан | Уточнить один маршрут |
| «На твой выбор» | Нет | Попросить пользователя выбрать |
| Два допустимых номера | Нет: выбор неоднозначен | Уточнить один номер |
| Предвыбранный UI-вариант, не отправленный пользователем | Нет | Ждать отправленного выбора |
