# Сохранение исходных байтов при узком ремонте

Установи разрешённую область изменения. Для AGENTS.md/CLAUDE.md разрешено лишь
согласованное создание или восстановление стартовых подключений через common
checker; это не разрешение прямой правки других настроек.

1. Сохрани исходные bytes каждого файла. Декодируй/кодируй UTF-8 без универсальной
   нормализации: `read_bytes().decode('utf-8')` → `write_bytes(text.encode('utf-8'))`.
   Обычный `read_text()/write_text()` может изменить CRLF вне разрешённой области.
   При ошибке кодирования не заменяй символы и не записывай повреждённый текст.
2. Оставь исходное содержимое и существующие окончания строк неизменными.
   Для новых вставок используй **первый LF/CRLF каждого файла отдельно**;
   при отсутствии перевода — LF. Не нормализуй весь файл, включая смешанные EOL.
3. Распознавание подключений и сравнение с Git учитывают CRLF. Ремонт добавляет
   только недостающее; второй запуск не дублирует импорт/ссылки и не создаёт
   ложных предупреждений. Git diff сам по себе не доказывает равенство bytes.
4. При реализации/проверке прочитай [регрессии](references/regressions.md):
   реальные временные LF/CRLF-файлы, байты вставок, импорт, повтор, Git warnings.
   Сохрани фактический результат; предложение исправления не означает успех теста.

В harness исправление уже находится в common/checks/ensure_entrypoint_links.py;
используй его и существующие тесты. Рабочий entrypoint один — common, без project wrapper и симлинков. До authoring/publication действуют канонические
скиллы и gate; сроки и равенство смысла не расширяют разрешённый ремонт.
