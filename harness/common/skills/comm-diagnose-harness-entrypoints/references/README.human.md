# Пояснение человеку

В папке — инструкция одной задачи и условные справочные материалы. Например,
SKILL.md помогает выбрать процедуру, а references уточняет отдельный её шаг.
Наличие папки и человеческого пояснения не доказывает результаты проверки;
актуальная область и ограничения перечислены в датированном отчёте.
