# Черновик проверки обычного запуска

SKILL.md содержит предлагаемый переносимый алгоритм проверки готовности
пользовательской команды. Это кандидат внутри заявки, не установленный скилл.

Пример: тест использовал временный путь модели. Алгоритм требует выяснить,
откуда обычный запуск получит рабочий путь, и проверить затронутую функцию
в пределах разрешённых действий.
