# Разделение окружения Python и моделей

Created: 2026-10-16T12:43:23+03:00 (Europe/Minsk).

Согласованный результат — переносимая lazy-процедура управления локальными
моделями. Её владелец — common, с именем comm-manage-local-models.
Модельные файлы размещаются в <корень проекта>/rag/local_models/,
вне .venv. Git хранит каркас, манифест, код, профили и тесты;
веса и сопутствующие скачанные файлы не индексируются. Манифест находится
вне исключённого каталога. Конкретные модельные идентификаторы и секреты
не входят в переносимую инструкцию.

Обоснование: пересоздание Python-окружения не должно удалять ресурсы,
а установка из Git должна воспроизводимо получать проверенный набор моделей.
Точная ревизия и контрольные суммы фиксируют набор; выпуск связывает его
с совместимой версией кода и тестов. Отдельная подготовка позволяет main
проверять готовность без неявного скачивания гигабайтов.

Существующие владельцы сохраняются: comm-separate-application-config —
размещение конфигов/секретов и Git-видимость; comm-verify-application-startup —
обычный запуск. Новый скилл отвечает за независимый жизненный цикл моделей.
Постоянное правило и изменение общего шаблона project не требуются.

Создание процедуры и каркаса не является переносом текущих весов,
реализацией загрузчика или изменением настроек приложения. Эти операции
требуют отдельного поручения с подходящими проверками.
