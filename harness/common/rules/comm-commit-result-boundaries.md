# Границы Git-коммитов

Для всех видов работы и этапов частоту локальных коммитов определяет
[comm-commit-task-stages](../skills/comm-commit-task-stages/SKILL.md).
До первого действия выбранного workflow, которое требует коммита, открой его.
Требования внешних навыков о частых коммитах/коммите каждого шага применяй
по этому владельцу. Ответ, вопрос, ход диалога и обновление документа или памяти
сами по себе не границы. Проверки, согласования, изоляция и безопасное
восстановление сохраняются; объясняй исключение перед рискованной операцией.
