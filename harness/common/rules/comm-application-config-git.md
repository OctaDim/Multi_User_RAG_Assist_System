# Конфигурация приложения и Git

При создании или изменении конфигурации приложения отделяй общие настройки
без секретов и шаблоны с заглушками, сохраняемые в Git, от рабочих локальных
параметров установки и секретов, исключаемых через .gitignore. Не скрывай
общие конфиги и шаблоны общим запретом формата файлов. Браузеру доступны
только публичные параметры; секреты бэка не передавай во frontend.

До записи конфигов, изменения их Git-видимости или добавления в индекс открой
из корня проекта
`harness/common/skills/comm-separate-application-config/SKILL.md`.
Проверяй фактический индекс: .gitignore не прекращает отслеживание уже
добавленных файлов и не удаляет секреты из истории.
