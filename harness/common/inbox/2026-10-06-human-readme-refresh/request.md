# Актуализация человеческих пояснений harness

Дата создания: 2026-10-06.

## Контекст

- Когда возникла потребность: после полного аудита harness, пункт 3 отчёта о двух
  отсутствующих README.human.md; 2026-10-06 пользователь расширил задачу на все
  человеческие пояснения проекта.
- Обстоятельства: в candidate/.claude/ и candidate/.claude/rules/ заявки
  2026-10-05-rules-entrypoint пояснений нет. Часть других README описывает уже
  заполненные категории как пустые, содержит прежнее количество правил,
  прежнее назначение inbox либо одинаковое описание разных архивных папок.
- Причина: пояснения не обновлялись вместе с наполнением категорий и уточнением
  контрактов; два вложенных каталога кандидата пропущены при оформлении.
- Что решит выполнение: человек сможет отличить действующие материалы,
  установочные копии, временные заявки, исторические комплекты и пустые категории.
- Требуемый результат: проверить все README.human.md проекта, обновить устаревшие
  и недостаточные пояснения, добавить два отсутствующих файла, сохранить примеры
  и их объяснения, равенство человеческих файлов в текущих копиях скилла и
  доказательства результата вне inbox.

## Разрешение и область

Пользователь поручил: «3 а также проверь и актуализируй все файлы
README.human.md, дополни при необходимости». После предложения одной заявки
явно подтвердил: «создать и выполнить одну заявку».

Разрешены создание и выполнение этой единственной заявки. Чтение человеческих
пояснений разрешено для их проверки и актуализации в этой задаче; они остаются
документацией для человека, а не источником инструкций агента. Обычный порядок
исключения этих файлов из контекста, поиска знаний и оценки скилла не меняется.

Рабочие инструкции, правила, скрипты, прочие заявки и AGENTS.md/CLAUDE.md
не редактируются. Обновляются только README.human.md, учёт данной заявки
и отдельное постоянное доказательство проверки. Полная нативная приёмка
скиллов/правил в эту задачу не входит; непроверенные статусы не повышаются.

## Выполнение

Дата обновления: 2026-10-06.

- **Статус:** выполнена.
- **Результат:** проверены 128 прежних пояснений; 118 обновлены, десять сохранены
  без изменений. Созданы два пропущенных пояснения и README этой заявки.
  Во всех 124 папках harness есть пояснения; в проекте их 131. Полные текущие
  копии скилла совпадают с источником, остальные прежние файлы области задачи
  и защищённые входы не изменены. Постоянные
  [доказательства](../../testing/evidence/2026-10-06-human-readme-refresh-evidence.md) сохранены вне inbox.
- **Причина:** требуемая актуализация и дополнение человеческих пояснений
  выполнены; структурная проверка, ссылки, равенство копий, quick_validate.py
  и git diff --check проходят. Обязательная работа этой заявки завершена.
