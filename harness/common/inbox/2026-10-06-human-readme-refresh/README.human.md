# Актуализация человеческих пояснений

Временная папка одной заявки на проверку и обновление всех README.human.md
проекта, включая пояснения архивных комплектов и нативных копий скилла.

Пример: request.md описывает два пропущенных пояснения, расширенную область
работы, разрешение пользователя и статус выполнения. Эти сведения позволяют
понять, что было поручено и какой результат получен.

Постоянный отчёт хранится в harness/common/checks/human-readme-refresh-evidence.md.
Он сохраняет результат проверки после удаления этой временной заявки.
Это пояснение предназначено человеку и не является инструкцией агента.
