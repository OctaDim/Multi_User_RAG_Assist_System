# Заявка об обязательном порядке инструкций

Здесь находится предложение общего правила о порядке правил, скиллов и остальных процедур harness, а также проверка генератора стартовых входов. Например, при рассмотрении заявки можно открыть полный кандидат правила и увидеть, что новый вход сейчас ставит INDEX.md перед START.md. Создание заявки не устанавливает правило и не исправляет генератор.
