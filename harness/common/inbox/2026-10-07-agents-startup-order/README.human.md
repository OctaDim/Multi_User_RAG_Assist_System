# Заявка о порядке старта

Здесь хранится предложение заменить стартовый AGENTS.md вариантом пользователя, его точная копия и результаты проверки. Например, при рассмотрении заявки можно сверить копию файла с указанной контрольной суммой и увидеть порядок чтения правил в журнале Codex. Само создание заявки ещё не применяет исправление.
