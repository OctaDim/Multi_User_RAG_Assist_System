# Общий harness

Обязательный переносимый пакет; полнота нативного подключения ещё не проверена. Перенос только common создаёт пустой project по base/project-skeleton.json; перенос обоих пакетов сохраняет существующий project.

Ищи по имени и содержимому категории, исключая `README.human.md`. Скиллы выбирай через нативные name/description; детали читай по задаче. Новый файл не требует строки в карте. В testing/: acceptance/ — критерии, tests/ — тесты, evidence/ — свидетельства.

Рабочее поведение принадлежит rules/skills и условным ресурсам; документы
сохраняют основания и формальные контракты. До записи опыта skills-first
по comm-process-harness-inbox; готовая инструкция не требует новой записи.

Заявки inbox могут быть удалены. Опыт, знания, решения, контракты, найденные решения и межсессионную память сохраняй вне inbox в соответствующих категориях; запись только в заявке не считается сохранением.

До выбора процедуры: канонические требования приоритетнее индивидуальных; skip/override запрещены. Любые изменения harness — через подтверждённый inbox; прямой путь требует явного указания и отдельного положительного ответа после вопроса агента. Перед изменением открой skills/comm-process-harness-inbox/SKILL.md. Автоматическое создание только отсутствующего пустого project стартовой проверкой из согласованного шаблона — узкое разрешённое исключение; существующий project не меняется. Прямые правки AGENTS.md и CLAUDE.md запрещены договорённостью harness, но технически не заблокированы; изменения — через inbox. Согласованное создание и восстановление стартовых ссылок — узкое исключение.
