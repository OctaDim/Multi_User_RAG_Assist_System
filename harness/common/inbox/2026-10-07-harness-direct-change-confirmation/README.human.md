# Заявка о прямых изменениях harness

Здесь предложено уточнение существующего скилла и правила владения: обычные изменения проходят через inbox, а прямое изменение по однозначной просьбе требует отдельного подтверждения после вопроса агента. Например, просьба исправить тест прямо в harness ещё не разрешает начать исправление до ответа на такой вопрос. Кандидаты не установлены.
