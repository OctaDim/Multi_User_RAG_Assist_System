# Компактные скиллы по задачам

Здесь заявка на улучшение процесса создания и изменения скиллов harness.
Например, перед добавлением новой процедуры нужно решить, относится ли она
к прежней задаче или заслуживает отдельного скилла.

request.md описывает результат и приёмку. source-skills содержит полную
исходную редакцию для сравнения; отчёты evaluate-skill оценивают эту редакцию,
а не ещё не подготовленные исправления. Заявка пока не выполнена.
