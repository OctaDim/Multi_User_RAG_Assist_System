# Validate the current version

Identify version, target kind, contract, modes, available tools and authorized
checks. Before tests read [validation](references/validation.md); before plugin-eval
read [evaluation](references/evaluation.md). For content/profile checks read from
root `harness/common/skills/comm-create-lazy-claude-codex-skills/references/content-contract.md`.

1. Run applicable mandatory checks on the final compact version; separate
   structural, budget, code and native behavior findings. Missing tools/checks
   remain unverified; warn and offer authorized installation.
2. Repair confirmed causes only when authorized, then repeat ALL current
   mandatory checks. Never inflate drafts, thresholds or coverage to get A.
3. Record startup+metadata, comparable actual reads with ALL dependencies and
   full available resources separately, with baseline paths/versions/limits.
4. Report date/version/files/commands/tools/agent versions/scope/contract,
   compactness/actual thresholds/baseline differences/excess reasons,
   pass/fail/not-run/N/A+reason, findings/missing tools/next steps and statuses
   separately for each agent/mode.

Done: truthful current results with no unresolved correctness/discovery/behavior
 gaps for verified scope. Edits reset statuses. This does not publish; copying
or permission never upgrades status. Saving results follows the authorized
inbox/evidence route.
