# О чём эта заявка

Здесь находятся запрос и материалы проверки порядка обработки inbox.
Например, если ранняя заявка ждёт выбора пользователя между двумя вариантами,
поздняя заявка остаётся в очереди; неверное имя файла с известным исправлением
агент исправляет самостоятельно. Статус выполнения указан в request.md.
