# Заявка о готовности обычного запуска

Здесь хранится запрос на общее правило, которое отличает успешные тесты от
готовности приложения к пользовательскому запуску. request.md содержит контекст,
границы разрешения и критерии. Соседний comm-application-startup-readiness.md —
полный черновик правила, папка comm-verify-application-startup — черновик скилла.

Пример: тест передал путь модели через переменную окружения, но обычная команда
не получает этот путь. Заявка требует обнаружить этот разрыв до заявления о готовности.
Создание заявки не означает её выполнение или публикацию.
