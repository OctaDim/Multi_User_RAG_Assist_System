# Планы изменений harness

Здесь хранятся переносимые планы с требованиями, решениями и проверяемыми критериями. Например, план двух режимов установки объясняет, как common создаёт пустой project и как сохранить уже перенесённый project. План описывает будущую работу и сам по себе не доказывает её выполнение.
