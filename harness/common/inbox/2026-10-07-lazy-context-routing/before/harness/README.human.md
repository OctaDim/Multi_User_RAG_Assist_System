# Harness в историческом снимке

Папка объединяет сохранённые пакеты конкретной прошлой редакции harness.

Пример: common/ содержит общий пакет; наличие project/ определяется составом исторического снимка.

Это человеческое пояснение, а не агентская инструкция. Исторический снимок и его результаты не подтверждают текущую версию harness.
