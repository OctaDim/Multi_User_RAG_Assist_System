# skills/ — пояснение для человека

Процедуры, открываемые по задаче. Навыки с кратким описанием запуска и необходимыми локальными ресурсами.

Материалы исходного проекта EPL; правила других проектов сюда не подставляются.

Пример: Навык запуска релевантных тестов EPL.

Он использует команды и ресурсы EPL; каталог пока не содержит готового навыка.

Пример иллюстративный. Структура создана заранее; рабочие материалы категории ещё предстоит собрать и проверить.
