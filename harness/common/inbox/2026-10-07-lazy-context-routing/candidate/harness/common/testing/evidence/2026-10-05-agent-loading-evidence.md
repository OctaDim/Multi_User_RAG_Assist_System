# Загрузка контекста и внешние основания

Исследование: 2026-10-04. Перенос: 2026-10-05.
Версии и возможности платформ — сведения на дату исследования; перед выбором способа подключения проверить актуальную официальную документацию и установленный рантайм. Нативная загрузка нового harness пока не проверена.

## Совместимость и переносимость

Официальная документация Claude Code на дату проверки описывает прямую загрузку AGENTS.md с v2.1.277, условия выбора между CLAUDE.md и AGENTS.md и дополнительные ограничения отдельных сессий до v2.1.281. `CLAUDE.md` с `@AGENTS.md` остаётся документированным способом совместимости; обычная просьба прочитать файл не эквивалентна импорту.
Источник: https://code.claude.com/docs/en/memory

Codex использует AGENTS.md и ограничивает суммарный размер проектных инструкций параметром project_doc_max_bytes (по умолчанию 32 KiB). Лимит — потолок совместимости, не целевой бюджет нового harness.
Источник: https://learn.chatgpt.com/docs/agent-configuration/agents-md

Автоматическое обнаружение скиллов зависит от стандартных каталогов конкретного агента. Простое помещение произвольной папки harness в проект не доказывает обнаружение её скиллов. Способ подключения нужно согласовать и проверить отдельно.

## Внешние основания

- OpenAI: короткий AGENTS.md как карта; поддерживаемые знания в репозитории; отдельные механические проверки связности и актуальности. https://openai.com/index/harness-engineering/
- Mitchell Hashimoto: найденный повторяемый промах следует превращать в обратную связь через инструкции и работающие инструменты. https://mitchellh.com/writing/my-ai-adoption-journey
- Birgitta Böckeler, martinfowler.com: harness включает детерминированные инструменты и устройство доступного агенту контекста. https://martinfowler.com/articles/exploring-gen-ai/harness-engineering-memo.html
- Foundation Capital: общие правила и контекст конкретных решений — разные виды знаний; важны основания исключений и подтверждения. Использование Markdown для такого следа — наше возможное решение, не требование статьи внедрить графовую БД. https://foundationcapital.com/ideas/context-graphs-ais-trillion-dollar-opportunity
- Claude Code: memory и skills задают разные механизмы загрузки. https://code.claude.com/docs/en/memory ; https://code.claude.com/docs/en/skills
- Context7: `/websites/code_claude`, запрос о загрузке AGENTS.md и обнаружении скиллов; результаты сверены с официальной memory-документацией.
