# handoffs/ — пояснение для человека

Передача незавершённой задачи следующей сессии. Минимальный контекст продолжения: цель, состояние, подтверждённые факты, ограничения и следующий шаг.

Универсальные материалы, применимые в разных проектах.

Пример: Универсальный шаблон передачи: цель, проверенное состояние и следующий шаг.

Шаблон применим в разных проектах; факты конкретной сессии принадлежат проектному пакету.

Пример иллюстративный. Структура создана заранее; рабочие материалы категории ещё предстоит собрать и проверить.
