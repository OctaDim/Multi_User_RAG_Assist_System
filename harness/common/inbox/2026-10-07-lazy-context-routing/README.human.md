# Разделение контекста

Здесь находятся заявка, кандидаты и проверки переноса процедур из постоянных
правил в скиллы. Например, порядок закрытия inbox загружается при обработке
заявок, а ограничение на публикацию остаётся видимым до выбора процедуры.
Эта папка временная; готовые знания публикуются в постоянных категориях.
