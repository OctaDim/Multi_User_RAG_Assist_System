# Заявка о нормализации окончаний строк

Здесь предложена политика для смешанных LF/CRLF: обычный текст приводить к LF,
Windows batch-файлы — к CRLF. Например, согласованная нормализация смешанного
Markdown-файла заменяет CRLF на LF во всём указанном файле.
Заявка и кандидат пока не исполнены и не опубликованы.
