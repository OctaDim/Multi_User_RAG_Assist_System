# Удаление старого проектного пути стартовой проверки

Здесь заявка на очистку поддержки старой обёртки и обновление её тестов.
Например, проверку отказа при небезопасном пути сначала сопоставляют с общим
скриптом, а затем переносят полезный сценарий без потери проверки безопасности.

request.md содержит требования, найденные источники и критерии приёмки.
Общий скрипт должен остаться без изменений; выполнение заявки ещё не начато.
