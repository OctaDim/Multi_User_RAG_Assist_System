# Пояснения исторических контейнеров

Эта заявка касается только отсутствующих README в 14 папках исторических снимков. Например, request.md описывает решение пункта 8 аудита, а human-guide-candidates.json показывает назначение каждого подготовленного пояснения. Кандидаты не применены; другие замечания аудита сюда не входят.
