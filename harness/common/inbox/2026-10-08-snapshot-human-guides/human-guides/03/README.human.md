# Скиллы в историческом снимке

Папка хранит полные установочные копии скиллов прошлой редакции.

Пример: example/SKILL.md и его ресурсы образуют одну папку скилла; пример иллюстративный.

Это человеческое пояснение, а не агентская инструкция. Исторический снимок и его результаты не подтверждают текущую версию harness.
