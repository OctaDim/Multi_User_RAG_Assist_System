# Общая часть сохранённого harness

Часть заявки «Подключение правил обоим агентам»: `candidate/harness/common/`. Это сохранённый кандидат на этапе подготовки и проверки. Это временные материалы внутри inbox, а не установленный пакет. Каталог содержит сохранённые файлы.

Пример: `START.md` содержит обязательные стартовые границы соответствующей версии пакета.

Файл позволяет рассмотреть именно этот аспект сохранённой версии. Рабочие файлы этапа сохранены; пояснение не делает их текущими инструкциями.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
