# Проверка входов без индивидуальной настройки

Уточнение пользователя 2026-10-05 отменяет Git hook, блокирующие проверки и обязательную регистрацию версии входов. Прямое редактирование AGENTS.md и CLAUDE.md запрещено договорённостью harness, но технически не заблокировано. Предложения изменения — через согласованную отдельную обработку inbox. Наличие заявки само по себе не разрешает правку.

## Запуск

Нужен Python 3.9+. Из корня проекта:

```sh
python3 -B harness/common/checks/ensure_entrypoint_links.py
```

Не требуются Git, hooks, hooksPath, изменения конфигурации машины или предварительная регистрация входов. Скрипт не запускается сам: его запускает агент по стартовой инструкции. Он не изменяет Git-настройки и не блокирует запись или коммит.

## Что проверяется

- Наличие INDEX.md/START.md установленных пакетов и обычные безопасные входные файлы.
- Стартовые Markdown-ссылки INDEX.md/START.md, ссылка на .claude/rules/ и явное указание Codex прочитать Markdown-правила рекурсивно (кроме README.human.md) в AGENTS.md; относительный импорт в CLAUDE.md. Отсутствующий каталог .claude/rules создаётся; симлинки в пути или файл вместо каталога дают ошибку до правки входов. Перед восстановлением выводится сообщение о повреждении и предстоящей записи. Другие настройки не переписываются.
- CLAUDE.md должен содержать только @AGENTS.md и необязательный конечный перевод строки. Лишний или отличающийся текст сохраняется; проверка предупреждает и направляет исправление в inbox.
- Если Git уже доступен и содержит версии входов в HEAD, дополнительно сравнивается рабочий текст с историей. Для AGENTS.md стандартные строки стартовых ссылок и сгенерированное указание чтения правил не считаются изменением настроек. Обнаруженная правка вызывает предупреждение, а не блокировку.

При отсутствии Git или версии HEAD сравнение произвольных настроек AGENTS.md с прошлым не проверено: без предыдущего текста нельзя доказать их неизменность. Структура и импорт проверяются независимо. Текущее содержимое не сохраняется автоматически как новое основание сравнения.

Сообщение проверки:

> Прямое редактирование AGENTS.md и CLAUDE.md запрещено договорённостью harness, но технически не заблокировано. Изменения предлагайте через заявку в harness/<пакет>/inbox/.

Предупреждения об изменённом тексте не меняют код успешного завершения и не блокируют задачу. Повреждение ресурсов, небезопасные пути и ошибки чтения/записи могут завершить проверку ошибкой: это невозможность безопасно выполнить её, а не технический запрет редактирования.

## Проверки

```sh
.venv/bin/python -m pytest harness/common/checks/test_ensure_entrypoint_links.py
.venv/bin/python -m pytest harness/common/checks/test_entrypoint_notifications.py
```

Проверяются работа без Git, сохранение прямых правок и лишнего текста, предупреждение до записи восстановленных ссылок, отсутствие ложного сообщения о повреждении, отсутствие установленных hooks/новых настроек и возможность обычного коммита после предупреждения.

В целевом проекте удалён только hook, установленный в этой задаче; чужие hooks не трогались. Старое описание блокировки и старые тесты блокирующей политики сохраняются в истории Git; они не являются действующим контрактом.

## Независимый запуск

В project-only команда использует `harness/project/checks/ensure_entrypoint_links.py`:
это автономная обычная установочная копия. Исходник находится в common/checks;
для исполнения проектной копии исходник не нужен. Новое создание согласованного
статичного AGENTS.md выбирает common при его наличии, иначе project. Действующая
стартовая команда уже существующего AGENTS.md не переписывается. Если она требует
удалённый пакет, нужно предложение изменения через inbox, а не молчаливая правка.

При обновлении в агрегирующем проекте редактировать common-исходник один раз, затем
копировать в project/checks и сравнить файлы. Не дублировать правила и документы.
В standalone project замена технической копии на предоставленную согласованную
версию не должна требовать доступа к отсутствующему common.

При установленном common дополнительная проверка:

```sh
.venv/bin/python -m pytest harness/common/checks/test_entrypoint_portability.py
```

Она проверяет только фактически установленные пакеты. Отсутствующие режимы и
недоступное сравнение с соседней копией явно помечаются непроверенными. Полная
матрица трёх режимов проверяется там, где обе исходные папки доступны для копирования.

## Незавершённое

Изолированный запуск проверки входов в трёх режимах подтверждён отдельно от
полноты всего harness. Фактическая нативная загрузка Codex/Claude Code, полный
аудит ресурсов/команд пакетов и стартовые токен-бюджеты ещё не приняты.

## Подключение правил, 2026-10-05

Ссылка в AGENTS.md не является встроенным импортом каталога: чтение Codex задаётся отдельной обязательной инструкцией. Скрипт проверяет подключение, а не содержание, комплектность или нативную загрузку правил; он не выполняет публикацию и копирование. Статусы и перенос правил совпадают со скиллами по [контракту](skill-rule-ownership-contract.md).
