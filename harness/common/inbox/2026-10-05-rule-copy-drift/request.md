# Полнота установочных копий общих правил

- Дата заявки: 2026-10-05.
- Когда возникла потребность: 2026-10-05, при диагностике расхождения
  `harness/common/rules/` и `.claude/rules/octadim/` по вопросу пользователя.
- Обстоятельства: в канонической папке пять правил, в нативной три;
  три существующие копии совпадают побайтово. Стартовая проверка успешна.
- Причина: правила копировали выборочно. Проверка входных ссылок не проверяет
  состав и равенство установочных копий.
- Что решит выполнение: восстановит комплект установленных правил и позволит
  обнаруживать пропуск, устаревшую копию и симлинк отдельной файловой проверкой.
- Требуемый результат: обычные одинаковые копии всех общих правил установленных
  пакетов; воспроизводимая проверка полного набора с негативными контролями;
  сохранённый опыт без новой always-loaded инструкции.

Пользователь: «исправь, сохрани опыт в harness».
Это разрешает исправление и сохранение опыта в inbox. Затем пользователь
ответил «разрешаю» на вопрос об установке двух текущих кандидатов в
`.claude/rules/octadim/` как непроверенных с сохранением этого статуса.
Разрешение относится только к двум указанным ниже копиям текущей версии.

## Опыт

При установке общих правил сверять весь набор канонических `comm-`/`proj-`
файлов с нативными копиями: наличие, отсутствие лишних общих правил,
обычные файлы без симлинков и равенство байтов. Проверять весь набор, а не только
файлы текущего изменения. Индивидуальные правила и README.human.md в сравнение
не входят. Успех проверки входных ссылок не подтверждает комплектность правил.

Проверка: `python3 -B harness/common/checks/test_rule_copies.py`.
При переносе общего опыта в lessons сохранить эти границы; сейчас опыт остаётся
в заявке до отдельной обработки.

## Выполненное исправление

Без изменения канонических текстов восстановлены обычные копии:

- `harness/common/rules/comm-human-folder-guides.md` →
  `.claude/rules/octadim/comm-human-folder-guides.md`.
- `harness/common/rules/comm-package-independence.md` →
  `.claude/rules/octadim/comm-package-independence.md`.

Перенос выполнен по явно разрешённому исключению текущего
[правила владения](../../rules/comm-skill-rule-ownership.md), статусы
Codex и Claude остаются «не проверено нативно».
Результаты и ограничения — в [отчёте](validation.md).
