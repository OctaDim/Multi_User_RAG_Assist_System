# Диагностика расхождения копий правил

Временная папка одной заявки: запрос, согласование, статус выполнения и сохранённые материалы соответствующего этапа. Наличие файлов не означает, что заявка требует повторного выполнения.

Пример: request.md содержит требуемый результат и раздел «Выполнение» со статусом, результатом и причиной.

Эти поля позволяют отличить завершённую работу от оставшейся. Постоянные знания и необходимые доказательства хранятся вне inbox; эта папка может быть удалена.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
