# Подробная разбивка ресурсов при оценке plugin-eval

Дата создания: 2026-10-07T23:12:27+02:00 (Europe/Berlin).
Потребность возникла в текущем обсуждении пункта 5 аудита harness 2026-10-07;
точное время исходного сообщения не зафиксировано. Проект:
GLOBAL_HARNESS_ENVIRONMENT. Пакет: common.

## Контекст, проблема и причина

Пользователь запросил lazy-скилл для подробного пользовательского вывода при
превышении порогов plugin-eval 1200 для ресурсов скилла и 1600 для generic-папки.
Общий deferred считает всю библиотеку ресурсов, поэтому одного общего числа
недостаточно для выбора файла, который надо сжать или разделить. Требуемый
вывод дополняет штатные категории, оценки, findings и бюджеты анализатора.

Дополнительно пользователь явно запросил создание заявки и такой же отчёт
для «Обработка inbox», «Авторство правил и скиллов», «Установка harness».
Свежие оценки этих существующих скиллов входят в состав заявки.

## Требуемый результат

Создать переносимый lazy-скилл `comm-report-plugin-eval-budget`, сохраняющий
штатный результат plugin-eval и добавляющий строки для каждого reference:

`SKILL.md=150/references/example.md=350 /Texts=500 --> 1000 (heavy-warn)`.

SKILL.md — весь файл; reference — отдельный текстовый ресурс; Texts — сумма
остальных учитываемых текстовых файлов, исключая SKILL.md и все references.
README.human.md исключать до оценки. Сумма строки включает один reference;
общая библиотека показывается отдельно. Состав Texts по файлам позволяет
выбрать конкретный файл для коррекции. Значения — статические оценки, не
реальный расход сессии и не весь обязательный стартовый контекст.

К каждой строке добавлять одну категорию по её сумме в скобках:
`good` — небольшой объём ≤180; `moderate` — умеренный 181–520;
`heavy-warn` — большой 521–1200, warn; `excessive-fail` — чрезмерный >1200, fail.
Например, сумма 851 получает `(heavy-warn)`. Это дополнительная оценка строки
по согласованной шкале, а не изменение исходных checks/bands plugin-eval
или статусов проверки агента. Автоматический trigger общего deferred
1200/1600 сохраняется отдельно от категории строки.

Внутри существующих общих скиллов и scripts такого формата не найдено.
Это самостоятельная компетенция с точным trigger, явно запрошенная пользователем.
Кандидат использует готовые JSON-компоненты установленного анализатора;
новый анализатор, tokenizer, dependency и постоянно загружаемое правило не нужны.

## Полный кандидат и размещение

Полная папка кандидата:
[comm-report-plugin-eval-budget/SKILL.md](comm-report-plugin-eval-budget/SKILL.md).
Дополнительные ресурсы не нужны; human guide входит в полный комплект.
После разрешённой обработки и публикационного gate будущий источник:
`harness/common/skills/comm-report-plugin-eval-budget/`. Полные обычные равные
копии: `.agents/skills/comm-report-plugin-eval-budget/` и
`.claude/skills/comm-report-plugin-eval-budget/`. Без symlink.

Не менять существующие скиллы, plugin-eval, thresholds анализатора, правила,
START/INDEX, статичные входы и общий шаблон. Локальные пути установки CLI
не включены в переносимую инструкцию. При удалении inbox постоянный скилл
должен сохранять работоспособность; постоянные результаты обработки размещать
в testing/evidence по контракту дат, а не оставлять только в заявке.

## Приёмка при последующей обработке

- Сохранить контракт; выполнить RED без кандидата, затем GREEN финальной версии.
- Skill deferred=1200: автоматического добавления нет; 1201: есть.
  Generic deferred=1600: нет; 1601: есть. Явный запрос работает ниже порога.
- При иной baseline сохранить исходный band/checks и показать различие порогов.
- Для S=150, refs=350 и 1000, Texts=500 получить строки 1000 и 1650;
  deferred=1850. Другие references не включаются в Texts или сумму строки.
- Категории суммы строки: 180 — good; 181 и 520 — moderate; 521 и 1200 —
  heavy-warn; 1201 — excessive-fail. Суммы 1000 и 1650 выше получают
  соответственно heavy-warn и excessive-fail. Вывод содержит одну категорию,
  штатные checks/bands исходной оценки не изменяются.
- Вложенные references и одинаковые basename различаются полными путями;
  все учитываемые references включаются, даже без Markdown-ссылки.
- Scripts/assets/config, учитываемые plugin-eval, входят в Texts с разбивкой;
  human guides и бинарные файлы не добавляются. Несовпадение суммы — ошибка.
- Без references показать SKILL.md+Texts; без Texts — обоснованный ноль.
  Неполные/недоступные данные не превращаются в нули.
- Generic-папка с несколькими скиллами сохраняет общий результат и отдельные
  оценки каждого скилла; папка без скиллов не получает выдуманный SKILL.md.
- Сохранить категории, score/grade, findings, бюджеты, bands, реальные
  thresholds и рекомендации; пояснить статическую методику и состав строки.
- Выполнить обязательные проверки финальной версии по процедуре авторства:
  skill-creator quick_validate, plugin-eval с human-фильтром, review/compare,
  Codex и Claude отдельно, common-only и common+project, явный вызов,
  неявный выбор, посторонняя задача без загрузки. Ресурсов собственного
  кандидата нет: собственный resource invocation — N/A с объяснением.
- При публикации проверить полный набор обычных равных native-копий,
  Git-видимость и изменение discovery/startup; перенос не повышает статусы.
