# Переработка трёх основных скиллов

Здесь заявка на разделение обработки inbox, авторства и установки harness по задачам.
Например, проверка существующего правила должна выбирать проверку инструкций,
а диагностика повреждённого входа — диагностику входов.

request.md содержит целевую структуру и критерии приёмки. source-skills и
source-rules сохраняют исходные материалы целиком; отчёты evaluate-skill —
точку сравнения. Выполнение идёт после заявки о требованиях к авторству.
