# Проверка статичного входа

До задачи запусти из корня проекта:

```sh
python3 -B harness/common/checks/ensure_entrypoint_links.py
```

Перед записью восстановленных ссылок показать: «Стартовые ссылки повреждены и будут
автоматически восстановлены.» При целых ссылках сообщение не выводить.
[Прямые правки запрещены договорённостью, но не заблокированы](comm-user-owned-entrypoints.md);
при обнаружении — предупреждение и направление в inbox, без hooks.

Нужен Python 3.9+. При диагностике из корня проекта открыть
`harness/common/docs/protected-entrypoints.md`.
В project-only используется собственная копия в project/checks. Новый согласованный
вход выбирает установленный пакет; команду существующего AGENTS.md не переписывать.
