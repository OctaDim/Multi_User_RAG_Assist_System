# Папки заранее; пояснения только для человека

Применяется при создании категорий harness, добавлении подпапок, подключении контекста или поиске знаний.

- Согласованную структуру harness создавай заранее, включая категории без рабочих материалов. При добавлении подпапки сразу создавай её пояснение. README не означает, что категория уже наполнена или проверена.
- В каждой папке harness, включая корни пакетов и вложенные папки, создавай `README.human.md`: простое объяснение категории, какие материалы здесь хранятся, наглядный пример и объяснение примера. Для пока пустой категории явно указывай, что пример иллюстративный.
- `README.human.md` предназначен для человека. Агентам запрещено читать его содержание и загружать его в контекст: при старте, маршрутизации, поиске и сборке материалов. Инструкции для агента хранятся отдельно; человеческое пояснение не является источником правил.
- Не включай эти файлы в агентские индексы, импорты, описания скиллов и стартовые инструкции. При поиске используй исключение, например `rg -n -g '!README.human.md' '<термин>' harness/`; не выводи их тела через общий cat, поиск или сборщик контекста.
- Проверка наличия и структуры пояснений может читать файлы программно, но возвращает агенту только результат, пути и ошибки, без их содержания. Создание пояснения не требует предварительной загрузки других человеческих пояснений.

Наличие этого файла само по себе не блокирует файловый доступ. Обязательность чтения правила, исключение из загрузчиков и поведение агентов нужно проверять отдельно; не объявляй полный запрет чтения технически обеспеченным по одной инструкции.
