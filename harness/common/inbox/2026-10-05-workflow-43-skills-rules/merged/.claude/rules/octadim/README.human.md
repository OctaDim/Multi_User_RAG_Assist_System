# Прежнее размещение копий правил

Часть заявки «Смысловой контракт скиллов и правил»: `merged/.claude/rules/octadim/`. Это объединённый комплект, подготовленный для публикации двух заявок. Путь отражает прежнюю схему; действующие копии правил размещаются непосредственно в .claude/rules/ проекта. Это временные материалы внутри inbox, а не установленный пакет. Каталог содержит только человеческое пояснение.

Пример: иллюстративный файл проверки или правила мог бы находиться в этой части комплекта; сейчас рабочих файлов здесь нет.

Пример только объясняет назначение пустого каталога и не утверждает наличие готового материала.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
