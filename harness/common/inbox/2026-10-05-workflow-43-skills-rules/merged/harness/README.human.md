# Сохранённая структура harness

Часть заявки «Смысловой контракт скиллов и правил»: `merged/harness/`. Это объединённый комплект, подготовленный для публикации двух заявок. Это временные материалы внутри inbox, а не установленный пакет. Каталог содержит подпапки комплекта.

Пример: `common/` — существующая подпапка с материалами этой части комплекта.

Подпапка помогает воспроизвести структуру сохранённого комплекта; она не означает, что весь пакет установлен или полностью проверен.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
