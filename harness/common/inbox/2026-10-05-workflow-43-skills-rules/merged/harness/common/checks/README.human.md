# Проверки сохранённого комплекта

Часть заявки «Смысловой контракт скиллов и правил»: `merged/harness/common/checks/`. Это объединённый комплект, подготовленный для публикации двух заявок. Это временные материалы внутри inbox, а не установленный пакет. Каталог содержит сохранённые файлы.

Пример: `test_rule_copies.py` проверяет набор обычных копий правил и совпадение их байтов с источниками.

Файл позволяет рассмотреть именно этот аспект сохранённой версии. Рабочие файлы этапа сохранены; пояснение не делает их текущими инструкциями.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
