# Документы сохранённого комплекта

Часть заявки «Смысловой контракт скиллов и правил»: `before/harness/common/docs/`. Это исходная версия до изменений данной заявки. Это временные материалы внутри inbox, а не установленный пакет. Каталог содержит сохранённые файлы.

Пример: `compact-authoring.md` описывает компактное создание инструкций и проверку сохранённого поведения.

Файл позволяет рассмотреть именно этот аспект сохранённой версии. Рабочие файлы этапа сохранены; пояснение не делает их текущими инструкциями.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
