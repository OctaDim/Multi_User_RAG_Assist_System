# Комплект материалов заявки

Часть заявки «Смысловой контракт скиллов и правил»: `before/`. Это исходная версия до изменений данной заявки. Это временные материалы внутри inbox, а не установленный пакет. Каталог содержит подпапки комплекта.

Пример: `harness/` — существующая подпапка с материалами этой части комплекта.

Подпапка помогает воспроизвести структуру сохранённого комплекта; она не означает, что весь пакет установлен или полностью проверен.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
