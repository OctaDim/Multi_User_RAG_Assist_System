# Скилл создания и публикации материалов

Сохранённая версия скилла в материалах заявки. SKILL.md содержит описание применения и короткую процедуру; references/ хранит подробности. Это снимок перед объединённой публикацией.

Пример: SKILL.md направляет к references/validation-and-publication.md для проверки итогового комплекта и условий публикации.

Так короткий вход сохраняет необходимые указатели, а детали доступны по задаче. Этот экземпляр описывает соответствующий этап заявки и не является текущей установкой.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
