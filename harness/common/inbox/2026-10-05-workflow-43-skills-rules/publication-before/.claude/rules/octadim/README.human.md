# Прежнее размещение копий правил

Часть заявки «Смысловой контракт скиллов и правил»: `publication-before/.claude/rules/octadim/`. Это снимок перед объединённой публикацией. Путь отражает прежнюю схему; действующие копии правил размещаются непосредственно в .claude/rules/ проекта. Это временные материалы внутри inbox, а не установленный пакет. Каталог содержит сохранённые файлы.

Пример: `comm-entrypoint-links-rule.md` задаёт обязательную проверку стартового подключения harness.

Файл позволяет рассмотреть именно этот аспект сохранённой версии. Рабочие файлы этапа сохранены; пояснение не делает их текущими инструкциями.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
