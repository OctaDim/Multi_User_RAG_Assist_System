# Справочные материалы скилла

В этой версии находятся `placement-contract.md` и `validation-and-publication.md`. Они раскрывают требования к содержанию, размещению или проверке, перечисленные в SKILL.md. Это снимок перед объединённой публикацией.

Пример: validation-and-publication.md объясняет проверки и условия переноса подготовленного материала.

Документ помогает отделить наличие файлов от результата проверки. Это справочные файлы сохранённой версии, а не новая действующая инструкция.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
