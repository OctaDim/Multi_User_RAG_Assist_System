# Скилл создания и публикации материалов

Каноническая процедура создания, изменения, проверки и публикации скиллов и правил для Codex и Claude Code. SKILL.md содержит описание применения и короткую процедуру; references/ хранит подробности. 

Пример: SKILL.md направляет к references/validation-and-publication.md для проверки итогового комплекта и условий публикации.

Так короткий вход сохраняет необходимые указатели, а детали доступны по задаче. Полные обычные копии папки устанавливаются для обоих агентов; их совпадение не заменяет проверку поведения.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
