# Lessons: ошибки и найденные решения

Постоянные разборы повторяемых ошибок harness: симптом, причина, решение и связь с доказательством или регрессионной проверкой. Здесь уже описаны расхождение копий правил, сохранение CRLF и необходимость явного разрешения на работу с заявками.

Пример: comm-rule-copy-drift.md разбирает случай, когда проверка входа проходит, но часть нативных копий правил отсутствует.

Разбор объясняет, почему нужно сверять полный набор копий. Необходимый опыт сохраняется здесь, даже если временная заявка inbox позднее будет удалена.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
