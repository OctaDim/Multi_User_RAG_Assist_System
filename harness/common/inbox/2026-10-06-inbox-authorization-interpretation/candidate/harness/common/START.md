# Обязательные границы

AGENTS.md и CLAUDE.md напрямую не редактировать, включая ручные правки владельцем:
изменения — через согласованную отдельную обработку inbox. Исключение — согласованное
создание статичного входа и восстановление стартовых ссылок (включая .claude/rules/ и указание их чтения) с предупреждением до записи.
Прямое редактирование запрещено договорённостью harness, но технически не заблокировано;
проверка предупреждает, не блокируя запись или коммит. Индивидуальные настройки не нужны.

При создании скилла или правила сразу готовить компактную версию с сохранением
обязательного поведения. Проверять итоговый комплект; после изменений инструкций
или ресурсов повторять проверки. Статусы «Codex — проверено/не проверено» и
«Claude — проверено/не проверено» фиксировать отдельно для итоговой компактной версии.
Полная проверка требует успеха у обоих. Без неё перенос в канонические папки harness
и нативные папки — только с явным разрешением и подтверждением пользователя;
непроверенные статусы сохраняются. [Порядок](docs/compact-authoring.md) читать по этой задаче.

До выбора процедуры и перед созданием любой заявки прочитать
[rules/comm-skill-rule-ownership.md](rules/comm-skill-rule-ownership.md). Это короткое обязательное правило; подробную процедуру открывать при создании, изменении, проверке или переносе скилла либо правила.

Установка: только common с автоматическим созданием отсутствующего project либо common+project с сохранением проектных материалов. Описание каркаса — base/project-skeleton.json; его состав меняется только через common inbox и отдельное решение с отдельным подтверждением пользователя по rules/comm-package-independence.md.
