# Проверка входов без блокировки

Дата: 2026-10-05. Область: уточнённая проверка common, не весь harness.

## Уточнённое решение

Пользователь отменил Git hook и индивидуальную настройку машины. Подтверждена формулировка: прямое редактирование запрещено договорённостью harness, но технически не заблокировано. Проверка предупреждает и направляет предложение изменения через inbox, сохраняя текст. Узкое восстановление ссылок сопровождается сообщением до записи.

Удалён только установленный нами локальный pre-commit hook: его байты предварительно совпали с нашим образцом. Чужие hooks и Git-настройки не изменялись. Образец hook и тесты отменённой блокировки убраны из активного пакета; в Git сохраняется история. [Прежнее свидетельство](entrypoint-protection-evidence.md) помечено историческим.

## RED → GREEN

До изменения все 5 новых сценариев падали: обязательный Git, код ошибки на изменённый текст, блокирующая политика, отсутствие подтверждённого предупреждения без Git. После изменения добавлен ранее проверенный регрессионный тест порядка сообщения относительно write.

- `python3 -B harness/common/checks/test_entrypoint_notifications.py`: 6 тестов, OK.
- `python3 -B harness/common/checks/test_ensure_entrypoint_links.py`: 7 тестов, OK.

Тесты запускают реальную проверку в временных проектах. Проверены: отсутствие Git в PATH, неизменность входов при целых ссылках, сохранение изменённых настроек, сохранение лишнего текста CLAUDE, предупреждение с inbox, восстановление ссылки, сообщение до write и отсутствие ложного сообщения при следующем запуске. Реальный Git-проект подтверждает отсутствие новых hooks/изменений config и возможность коммита после предупреждения.

Прежний тест CLAUDE с лишним текстом обновлён согласно новому решению пользователя: требуется предупреждение и сохранение текста, вместо блокирующего кода ошибки. Существующие проверки опасных файлов и отсутствующих ресурсов сохранены: невозможность безопасного чтения/восстановления не означает запрет записи редактором.

## Что результат не доказывает

Без предыдущего текста нельзя обнаружить произвольное изменение настроек AGENTS.md. Если существующая история Git доступна, она используется без настройки; иначе сравнение отмечено непроверенным. Проверка структуры/импорта и предупреждение работают независимо от Git.

Код не перехватывает редактор, не предотвращает прямую правку и не ограничивает коммит. Он запускается по стартовой инструкции агента, а не самостоятельно. Корневые входы не редактировались этой доработкой.

Project-only ещё не исправлен, изоляция средствами ОС и нативные прогоны Codex/Claude не выполнялись. Полнота трёх режимов и стартовый токен-бюджет остаются непроверенными.

После публикации в целевом проекте выполнены оба тестовых файла: 6 + 7, OK. Реальный
стартовый запуск завершился кодом 0, вывел согласованное предупреждение и не вывел
ложного сообщения о повреждённых ссылках. SHA-256 корневых входов не изменился; локальный
pre-commit hook отсутствует. Проверены 49 внутренних Markdown-ссылок common без чтения
README.human.md и побайтное равенство двух обычных нативных копий правил.

Plugin Eval выполнил generic-анализ двух документов правил: 0 fail, 0 warn, оценка
635 токенов (estimated-static), observed usage отсутствует. Это не специализированная
приёмка SKILL.md/плагина, не живое измерение стартового контекста и не доказательство
нативной загрузки. Исходный EPL остался read-only; его Git status чист.
