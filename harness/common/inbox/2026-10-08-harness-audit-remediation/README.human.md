# Исправление исторических ссылок на lessons

Здесь хранится заявка только по пункту 9 аудита harness: две ссылки в старых
отчётах ведут к удалённым lessons. В request.md предложены точные замены
на существующую карту миграции и критерии проверки.

Например, ссылка на CRLF-урок будет вести к карте переноса требований;
исходный текст останется доступен через указанный Git-коммит.

Заявка новая. Создание решения не означает выполнение исправлений.
