# Docs: исследования EPL

Документация и исследования конкретного проекта EPL. Сейчас здесь есть epl-harness-audit.md — первичная инвентаризация механизмов исходного проекта, выявленных ограничений и направлений дальнейшего переноса.

Пример: отчёт разбирает, что проверяет исходный линтер правил и чего его успешный запуск не доказывает.

Такой разбор помогает переносить полезный механизм вместе с его границами, не выдавая наблюдение об исходнике за проверенное поведение нового пакета.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
