# handoffs/ — пояснение для человека

Передача незавершённой задачи следующей сессии. Минимальный контекст продолжения: цель, состояние, подтверждённые факты, ограничения и следующий шаг.

Материалы исходного проекта EPL; правила других проектов сюда не подставляются.

Пример: Передача незавершённого исправления EPL со ссылкой на ветку и последний результат выбранных тестов.

Следующая сессия проверяет состояние и продолжает с указанного шага; передача не заменяет постоянный урок.

Пример иллюстративный. Структура создана заранее; рабочие материалы категории ещё предстоит собрать и проверить.
