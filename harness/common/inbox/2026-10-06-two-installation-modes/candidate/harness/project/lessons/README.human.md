# lessons/ — пояснение для человека

Ошибки, конфликты и проверенные решения. Повторяемый симптом, причина, эффективное решение и доказательство.

Материалы исходного проекта EPL; правила других проектов сюда не подставляются.

Пример: Урок EPL о неверном выборе адресата уведомления MAX.

Разбор относится к конкретному каналу и связывает причину с защитным тестом.

Пример иллюстративный. Структура создана заранее; рабочие материалы категории ещё предстоит собрать и проверить.
