# Одинаковая структура common/project с handoff

Дата: 2026-10-04. Статус на момент эксперимента: структура создана и проверена; полный harness ещё не собран.

## Подтверждённое решение

Пользователь выбрал одинаковые категории обеих папок и добавил handoff/. Созданы base/, decisions/, lessons/, testing/, rules/, skills/, checks/, inbox/, docs/, handoff/ в каждом пакете. Каждая папка harness, включая корни пакетов, имеет README.human.md с объяснением категории и примером. Индексы не ссылаются на человеческие пояснения.

В common/handoff/ предназначены универсальные шаблоны и процедуры передачи. В project/handoff/ предназначен контекст конкретных незавершённых задач проекта. Пока обе категории содержат только человеческие пояснения; шаблон или действующий handoff не создавались.

## Выполненная проверка

Из канонического проекта на момент эксперимента подготовлены три отдельные временные копии. Проверены точный набор категорий, наличие собственных индексов и человеческих пояснений с примером, существование ссылок и отсутствие ссылок за пределы каждого пакета.

В повреждённой копии project проверка отвергла отсутствие README.human.md в handoff/. После восстановления пояснения удаление всей категории handoff/ также вызвало отказ. В рабочем дереве пояснения есть в 23 из 23 папок harness. Тела пояснений программная проверка в контекст не выводила.

Оба исходных правила common сохранены без изменения тела. git diff --check прошёл. Рабочее дерево исходного проекта осталось чистым; его файлы, Git-метаданные и runtime-кеши не изменялись этой операцией.

## Границы результата

Это проверка каркаса и локальных ссылок. Размеры индексов не являются измеренным расходом токенов или стартовым контекстом агента. Численные бюджеты и способ подключения ещё не выбраны.

ОС не запрещала процессу обращаться к каноническому проекту или соседним каталогам; исходный проект не использовался. Неполное наполнение категорий, отсутствие исполняемых проверок и отсутствие подключения к Codex/Claude не позволяют объявить выполненной полную приёмку независимости, поведения и защиты. Однотипные краткие описания в индексах являются навигацией; общие правила в project не копировались.
