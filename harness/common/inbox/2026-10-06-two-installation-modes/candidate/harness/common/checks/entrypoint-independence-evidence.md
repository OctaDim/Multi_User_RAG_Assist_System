# Проверка входа и зависимость project-only

Статус: историческая диагностика исправленной зависимости стартового шаблона. Текущая [проверка трёх режимов](entrypoint-portability-evidence.md).

Дата: 2026-10-05. Это частичная диагностика, не приёмка всего harness.

Пользователь ответом «1» подтвердил узкое исключение: агент может создавать согласованный статичный AGENTS.md/CLAUDE.md и восстанавливать стартовые ссылки. Остальные настройки AGENTS.md остаются пользовательскими. Контракт: [пользовательский вход](../rules/comm-user-owned-entrypoints.md).

Проверены существующие файлы, без изменения исходного EPL:

- `python3 -B harness/common/checks/ensure_entrypoint_links.py` из GLOBAL_HARNESS_ENVIRONMENT: exit 0, `Entrypoint links OK`; обновлений скрипт не сообщил.
- `python3 -B harness/common/checks/test_ensure_entrypoint_links.py`: 7 тестов, OK. Они не проверяют фактический запуск стартовой команды в project-only.
- В чистую временную папку скопирован только project. Существующий common-скрипт вызван извне как установщик с аргументом временного корня: exit 0, созданы AGENTS.md/CLAUDE.md.
- Созданный AGENTS.md требует `python3 harness/common/checks/ensure_entrypoint_links.py`. В копии project-only этого файла нет; выполнение указанной команды из временного корня: exit 2, cannot open file / No such file or directory.

Вывод: текущий шаблон входа нарушает [независимость пакетов](../rules/comm-package-independence.md). Успешные семь тестов и совместный запуск эту ошибку не исключают. Диагностический вызов использовал исходный common-скрипт извне; это не доказательство изоляции или переносимости. Нативное обнаружение скиллов и запуск Codex/Claude Code здесь не проверялись.

Нужно согласовать способ независимой стартовой проверки. До решения шаблон и скрипты не исправлены, перенос авторских скиллов не продолжен. Согласие на исключение для AGENTS.md не отменяет независимость и запрет дублирования знаний.
