# Общий harness

Обязательный переносимый пакет; полнота нативного подключения ещё не проверена. Перенос только common создаёт пустой project по base/project-skeleton.json; перенос обоих пакетов сохраняет существующий project.

| Задача | Каталог |
|---|---|
| Базовые контракты и настройки | [base/](base/) |
| Решения и основания | [decisions/](decisions/) |
| Ошибки и решения | [lessons/](lessons/) |
| Тесты и регрессии | [testing/](testing/) |
| Обязательные ограничения | [rules/](rules/) |
| Переиспользуемые процедуры | [skills/](skills/) |
| Проверки harness | [checks/](checks/) |
| Временные заявки | [inbox/](inbox/) |
| Документы и прототипы | [docs/](docs/) |
| Продолжение задачи | [handoffs/](handoffs/) |

Ищи по имени и содержимому категории, исключая `README.human.md`. Скиллы выбирай через нативные name/description; детали читай по задаче. Новый файл не требует строки в карте.

Заявки inbox могут быть удалены. Опыт, знания, решения, контракты, найденные решения и межсессионную память сохраняй вне inbox в соответствующих категориях; запись только в заявке не считается сохранением.

До выбора процедуры: канонические требования приоритетнее индивидуальных; skip/override запрещены. Общий опыт — через подтверждённый inbox; прямое каноническое создание — по явному указанию пользователя. Прямые правки AGENTS.md и CLAUDE.md запрещены договорённостью harness, но технически не заблокированы; изменения — через inbox. Согласованное создание и восстановление стартовых ссылок — узкое исключение.
