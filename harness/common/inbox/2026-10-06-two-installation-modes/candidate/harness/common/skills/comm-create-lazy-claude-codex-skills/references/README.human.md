# Справочные материалы скилла

В этой версии находятся `content-contract.md` и `placement-contract.md` и `validation-and-publication.md`. Они раскрывают требования к содержанию, размещению или проверке, перечисленные в SKILL.md. 

Пример: validation-and-publication.md объясняет проверки и условия переноса подготовленного материала.

Документ помогает отделить наличие файлов от результата проверки. Content-contract описывает смысл и формат, placement-contract — источник и установочные копии.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
