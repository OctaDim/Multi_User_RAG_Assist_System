# Контейнер Claude в историческом снимке

Папка объединяет нативные материалы Claude, сохранённые для прежней проверки.

Пример: rules/ содержит правила, а skills/ — скиллы; пример поясняет назначение, а не гарантирует комплектность снимка.

Это человеческое пояснение, а не агентская инструкция. Исторический снимок и его результаты не подтверждают текущую версию harness.
