# Проверка статичного входа

До задачи запусти из корня проекта:

```sh
python3 -B harness/common/checks/ensure_entrypoint_links.py
```

Проверка восстанавливает ссылки INDEX.md/START.md подключённых пакетов, ссылку на .claude/rules/ и указание Codex прочитать все Markdown-правила каталога и подпапок до задачи, кроме README.human.md. Claude читает каталог нативно. До восстановления START/INDEX должны быть непустыми UTF-8 файлами, а установленный набор canonical comm-/proj- правил — полным, обычным и равным источникам. Пропуски, лишние копии, различия, недоступные пути и симлинки дают отказ; rules автоматически не публикуются.

Перед записью восстановленных ссылок показать: «Стартовые ссылки повреждены и будут
автоматически восстановлены.» При целых ссылках сообщение не выводить. Каждый распознанный блок проверяется отдельно: START common → START project → rules → INDEX common → INDEX project. Неверный порядок полного блока и неоднозначные частичные списки дают отказ без переупорядочения; однозначные пропуски восстанавливаются. Примеры в поддерживаемых fenced/inline-контейнерах не считаются подключением. Входы заменяются по одному атомарно после повторной проверки снимка; найденную параллельную правку сохранять, частичный результат сообщать.
[Прямые правки запрещены договорённостью, но не заблокированы](comm-user-owned-entrypoints.md);
при обнаружении — предупреждение и направление в inbox, без hooks.

Поддерживаются два режима по [контракту установки](comm-package-independence.md): перенос только common автоматически создаёт отсутствующий project из явного общего описания; при переносе обоих пакетов существующий project сохраняется. Common обязателен. Рабочая проверка одна: только common, прямой запуск обычного доверенного Python-файла. Project wrapper/launcher не создавать; отдельный project-only не поддерживается. Симлинки файла проверки, его предков, корня и используемых входных путей запрещены; обнаружение даёт отказ до восстановления. Стартовую команду существующего AGENTS.md не переписывать.

Нужен Python 3.9+. При диагностике из корня проекта открыть
`harness/common/skills/comm-diagnose-harness-entrypoints/SKILL.md`.

Разрешённое узкое исключение: обязательная стартовая проверка автоматически
создаёт только отсутствующий harness/project как пустой нейтральный каркас
из согласованного harness/common/base/project-skeleton.json, без inbox
и отдельного подтверждения. Существующий project сохраняется побайтно;
его правка, дополнение, пересоздание и изменение шаблона этим исключением
не разрешены.
