# Надёжность стартовой проверки

Здесь заявка на исправление проверки и восстановления стартовых ссылок.
Например, полный блок с неправильным порядком должен быть обнаружен,
а несколько потерянных ссылок повторного блока — восстановлены безопасно.

request.md содержит scope и критерии. source-contracts/ хранит исходные
контракты для будущей обработки. Создание заявки не означает её выполнения.
