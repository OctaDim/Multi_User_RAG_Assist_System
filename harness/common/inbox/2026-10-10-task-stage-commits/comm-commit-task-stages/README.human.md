# Коммиты на границах задач и этапов

Кандидат общего скилла определяет, когда сохранять работу, и использует
Compound Engineering ce-commit для создания локальных коммитов.
Например: исходные изменения → коммит, первый этап → коммит, второй этап
→ коммит. На границе без своих изменений пустой коммит не создаётся.
