# Вариант выполнения без специального маршрута

Здесь находится заявка на добавление нативного варианта в меню выбора способа
выполнения задачи. Например, пользователь выбирает работу текущей моделью
самостоятельно, сохраняя установленный effort.

request.md описывает запрос и статус; source-comm-confirm-development-workflow.md
содержит полный исходник правила на момент создания заявки. Создание заявки
не означает, что правило уже изменено.
