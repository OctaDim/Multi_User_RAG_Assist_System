# Заявка о доказательствах публикации

Здесь находится заявка на исправление одного отчёта: его доказательства
остались в старом inbox и могут пропасть при очистке.

Например, после выполнения заявки ссылка на publication-manifest.json будет
вести в постоянный testing/evidence, а не во временную папку заявки.
Создание заявки не означает, что исправление уже выполнено.
