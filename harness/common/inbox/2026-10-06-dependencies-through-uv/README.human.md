# Заявка об установке зависимостей через uv

Здесь находится временная заявка с контекстом, требованиями, планом обработки
и критериями приёмки. Создание заявки ещё не означает внедрение правила.

Например, установка тестового Python-пакета должна выполняться подходящей
командой uv. Для пакета другой экосистемы заявка предусматривает уточнение
границы применения с пользователем. Это пример требуемого поведения,
а не свидетельство выполненной проверки.
