# Справочные материалы кандидата

Часть заявки «Разделение правила и процедуры авторства»: `rule/references/`. Это кандидат правила данной заявки. Это временные материалы внутри inbox, а не установленный пакет. Каталог содержит сохранённые файлы.

Пример: `skill-rule-ownership-contract.md` разделяет общие и индивидуальные материалы, размещение и проверки.

Файл позволяет рассмотреть именно этот аспект сохранённой версии. Рабочие файлы этапа сохранены; пояснение не делает их текущими инструкциями.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
