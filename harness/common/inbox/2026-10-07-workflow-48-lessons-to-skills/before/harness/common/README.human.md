# Common: общие знания

Пакет общих материалов harness: ограничения, решения, уроки, процедуры, документация и проверки, применимые в разных проектах. INDEX.md помогает выбрать категорию, START.md содержит обязательные границы начала работы.

Пример: rules/comm-package-independence.md описывает независимость пакетов, а checks/test_entrypoint_portability.py проверяет автономный запуск входной проверки.

Правило задаёт требование, тест проверяет конкретный механизм его соблюдения; успешный тест не доказывает работоспособность всего пакета.

Сейчас имеются пять канонических правил и скилл comm-create-lazy-claude-codex-skills. Base, testing и handoffs пока содержат только пояснения. Полная нативная приёмка не завершена; inbox хранит временные заявки.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.


## Согласованная структура, 2026-10-06

После миграции используются 12 категорий: checks, scripts, testing, specs, docs, decisions, inbox, rules, skills, base, lessons, handoffs. В testing предусмотрены acceptance, tests, evidence. Даты в именах знаний означают создание и не меняются при правках.
