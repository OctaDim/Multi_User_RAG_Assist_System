# Проверять полный набор установочных копий правил

Подтверждённый опыт: 2026-10-05, [заявка](../inbox/2026-10-05-rule-copy-drift/request.md), [проверки и разрешение](../inbox/2026-10-05-rule-copy-drift/validation.md).

**Fails-when:** стартовая проверка успешна, но нативные копии общих правил неполны или устарели.

**What happened:** из пяти канонических правил установили только три; проверка входных ссылок не обнаружила пропуск двух копий.

**How to fix:** сверять весь набор `comm-`/`proj-` правил установленных пакетов: отсутствие пропусков и лишних общих копий, обычные файлы без симлинков и равенство байтов. Индивидуальные правила и README.human.md исключать. Использовать `.venv/bin/python -m pytest harness/common/testing/tests/test_rule_copies.py`; проверка включает негативные контроли пропуска, других байтов, симлинка и лишней копии для common-only с созданием project и совместного режима. Пустая выборка даёт отказ.

**Why should be fixed:** выборочное копирование оставляет часть обязательных требований неустановленной. Проверка входа подтверждает ссылки, а файловая проверка копий — комплектность; ни одна не доказывает нативную загрузку агентом. Восстановление копий проходит действующий gate публикации. Разрешённое исключение сохраняет реальные статусы Codex и Claude.
