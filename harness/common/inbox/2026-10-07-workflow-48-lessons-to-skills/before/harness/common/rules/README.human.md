# Rules: короткие обязательные границы

Пять канонических общих правил: проверка входов, защита статичных входов, независимость пакетов, человеческие пояснения и владение скиллами/правилами. Подробные процедуры, решения и доказательства находятся в других категориях.

Пример: comm-skill-rule-ownership.md запрещает индивидуальной процедуре отменять применимое каноническое требование проверки.

Префикс comm- обозначает общий источник. Обычные установочные копии этих правил находятся непосредственно в .claude/rules/ принимающего проекта; прежняя схема octadim/ отменена, новое личное размещение правил не вводилось.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
