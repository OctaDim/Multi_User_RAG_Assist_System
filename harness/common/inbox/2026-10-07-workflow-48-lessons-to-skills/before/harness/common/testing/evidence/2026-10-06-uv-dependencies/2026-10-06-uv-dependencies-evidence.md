## Контракт и область

До выбора установщика рабочие, тестовые и инструментальные Python-зависимости
устанавливаются через uv с сохранением версий, источников, формата и изоляции.
Недоступность uv не разрешает fallback. Подготовка uv рассматривается отдельно.
Для зависимостей вне возможностей uv необходимо решение пользователя до установки;
запуск другого установщика через uv run не заменяет это решение.
Постоянное правило нужно до выбора скилла: проверка может потребовать установку
зависимости до открытия процедуры авторства.

## Инвентаризация

Поиск выполнен в common/project, включая собственные скиллы, проверки и нативные
копии, с исключением README.human.md. Проверены команды pip/pipx/Poetry,
npm/pnpm/yarn и apt-get; действующих альтернативных команд установки не найдено.
Исторические отчёты и кандидаты не переписывались. Установленные Node.js и
plugin-eval использовались без установки. Фактических новых неподдерживаемых
зависимостей в этой заявке не выявлено; согласование гипотетического исключения
не подменялось решением агента.

  изолированный native probe; исходный проект и глобальные инструкции скрыты bwrap.

  uv tool install и повторный запуск. Все версии совпали. Эти версии — данные
  проверки, а не новые ограничения для проектов.
- Generic plugin-eval через launcher с human-фильтром: 100/A, без WARN/FAIL;
  статическая оценка 289 токенов. Это оценка plain rule, не скилла или плагина;
