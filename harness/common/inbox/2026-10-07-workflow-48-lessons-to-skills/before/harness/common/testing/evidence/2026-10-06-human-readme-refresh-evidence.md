# Актуализация человеческих пояснений

Дата: 2026-10-06. Объект: все README.human.md проекта, включая harness,
архивные комплекты inbox и существующие нативные папки .agents/.claude.

Пользователь явно поручил проверку и актуализацию всех пояснений, затем разрешил
«создать и выполнить одну заявку». Чтение их содержимого в этой задаче разрешено
для проверки самой человеческой документации. Это не меняет обычный запрет
включать её в инструкции агента, поиск знаний или оценку скилла.

- Проверены 128 существовавших пояснений: 118 обновлены, десять оставлены
  без изменений, поскольку соответствуют содержимому пустых категорий.
- Добавлены два отсутствовавших пояснения в candidate/.claude/ и
  candidate/.claude/rules/ прежней заявки о подключении правил.
- Для новой заявки создано собственное пояснение. Итого: 131 README.human.md
  в проекте; во всех 124 каталогах harness имеется обычный файл пояснения.
- Убраны устаревшие сведения о трёх правилах, незаполненности уже наполненных
  категорий, личном размещении правил и постоянном хранении опыта в inbox.
- Пояснения различают текущие источники, нативные копии, временные заявки,
  кандидаты, исходные снимки и объединённые комплекты. Примеры архивных папок
  относятся к реально существующим файлам или подпапкам; пустые категории
  сохраняют явно иллюстративные примеры.
- Обновлены человеческие пояснения общего скилла и его полных нативных копий.
  Изменены только человеческие документы; SKILL.md и машинные ресурсы сохранили
  свои байты. Рабочие файлы исторических комплектов и прежние доказательства
  не переписывались.

## Проверки

Проверка присутствия, обычных файлов, заголовков, примеров, поясняющих абзацев,
локальных Markdown-ссылок и полного равенства текущих копий выполнена: PASS.
Содержание проверено по фактическим файлам папок и действующим контрактам;
синтаксические проверки сами по себе не доказывают понятность текста человеку.

Сравнение SHA-256 с состоянием перед записью подтвердило: среди прежних файлов
harness/.agents/.claude изменены только 118 выбранных README; все прочие прежние
файлы этих каталогов и AGENTS.md/CLAUDE.md сохранили свои байты. Файлы IDE вне
области задачи могут изменяться независимо и не использованы для этого вывода.

Полные составы и байты шести файлов источника общего скилла и обеих нативных
копий равны; пять source/native правил также равны. skill-creator
quick_validate.py: exit 0, «Skill is valid!». git diff --check: exit 0.
Проверка входа перед работой завершилась успешно, без восстановления ссылок.

Повторяемая структурная проверка из корня проекта; она программно читает
пояснения, но возвращает только результат без их содержимого:

```sh
python3 -B - <<'PY'
from pathlib import Path
import re

root = Path('.')
folders = [root / 'harness', *filter(Path.is_dir, (root / 'harness').rglob('*'))]
assert all((folder / 'README.human.md').is_file() for folder in folders)
guides = [file for base in ('harness', '.agents', '.claude')
          for file in (root / base).rglob('README.human.md')]
for file in guides:
    assert file.is_file() and not file.is_symlink(), file
    text = file.read_text()
    assert re.search(r'(?m)^#\s+\S', text), file
    assert re.search(r'пример|например', text, re.I), file
    assert len([p for p in text.split('\n\n') if p.strip()]) >= 3, file
name = 'comm-create-lazy-claude-codex-skills'
def bundle(path):
    return {str(file.relative_to(path)): file.read_bytes()
            for file in path.rglob('*') if file.is_file()}
source = bundle(root / 'harness/common/skills' / name)
for base in ('.agents/skills', '.claude/skills'):
    assert bundle(root / base / name) == source, base
print(f'PASS: {len(folders)} harness folders, {len(guides)} guides; skill copies equal.')
PY
```
