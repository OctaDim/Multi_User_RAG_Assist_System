# Skills: процедуры по задаче

Общие скиллы с краткими условиями применения в SKILL.md и необходимыми ресурсами. Сейчас здесь установлен comm-create-lazy-claude-codex-skills — процедура создания, проверки и публикации скиллов и правил для Codex и Claude Code.

Пример: при подготовке нового скилла процедура направляет к references/validation-and-publication.md своего комплекта.

Справочные подробности открываются для выбранной задачи. Канонический источник хранится здесь, полные установочные копии — в .agents/skills/ и .claude/skills/ проекта; наличие копий само по себе не подтверждает нативную проверку.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
