# Checks: автономная проверка входа

Здесь находится ensure_entrypoint_links.py — автономная установочная копия общего механизма проверки входов. Она предназначена для режима, в котором установлен только project, и не читает отсутствующий common.

Пример: при установке только project команда python3 -B harness/project/checks/ensure_entrypoint_links.py проверяет ссылки INDEX.md и START.md установленного пакета.

Это проверка подключения harness, а не поведения приложения EPL. Исходник технической копии поддерживается в common; наличие этой копии не подтверждает полный перенос проектных знаний.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.


## Согласованная структура, 2026-10-06

После миграции здесь остаются исполняемые проверки harness. Тесты перенесены в testing/tests, критерии — в testing/acceptance, свидетельства — в testing/evidence; служебные скрипты — в scripts.
