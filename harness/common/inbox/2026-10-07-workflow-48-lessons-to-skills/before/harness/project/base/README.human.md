# base/ — пояснение для человека

Базовые настройки, ограничения и контракты. Исходные условия, с которыми проект или пакет начинает работу.

Материалы исходного проекта EPL; правила других проектов сюда не подставляются.

Пример: Принятые в EPL часовые пояса интерфейса и хранения времени.

Эти значения относятся к EPL и не становятся настройками других проектов.

Пример иллюстративный. Структура создана заранее; рабочие материалы категории ещё предстоит собрать и проверить.
