В common checker исправление уже реализовано: он читает и пишет входы через bytes, выбирает окончания новых строк отдельно для каждого файла и распознаёт CRLF-импорт. `read_text()/write_text()` здесь может нормализовать байты вне разрешённых вставок; одинаковый смысл и срок этого не оправдывают. Регрессионные тесты не запускаю, поскольку они создают временные файлы, а вы запретили любое создание.

Исправление уже есть в [common checker](/tmp/two-modes-native-rji7w3kk/workspace/harness/common/checks/ensure_entrypoint_links.py). Прямых правок, создания и публикации не выполнял.

- **Чтение/запись:** `read_bytes().decode('utf-8')` → `write_bytes(text.encode('utf-8'))`. `read_text()/write_text()` может нормализовать CRLF; одинаковый смысл и срок не разрешают менять исходные байты.
- **Вставки:** только отсутствующие подключения. EOL — первый LF/CRLF каждого файла отдельно, иначе LF. Исходное содержимое, включая смешанные окончания, сохраняется. В AGENTS добавляются ссылки; отсутствующий импорт CLAUDE добавляется перед сохранённым содержимым.
- **Повтор:** bytes должны остаться идентичными, без дубликатов и сообщения о восстановлении. Правильный `@AGENTS.md\r\n` распознаётся.
- **Git:** HEAD читается без нормализации; сгенерированные строки AGENTS исключаются из сравнения вне fenced-блоков, CLAUDE сравнивается целиком. Diff не заменяет проверку bytes.
- **Проверки:** нужны LF/CRLF fixtures, точные байты вставок, сохранение исходных байтов, повтор и отсутствие ложного Git warning.

Обязательный старт завершился успешно, без сообщения об обновлении входов. История проекта недоступна — сравнение с HEAD **не проверено**. Регрессии прочитаны, но не запускались: они создают временные файлы. Старый project wrapper в этом проекте отсутствует.
