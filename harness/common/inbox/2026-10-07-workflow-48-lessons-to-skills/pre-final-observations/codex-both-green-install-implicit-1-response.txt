|---|---|
| common-only, project отсутствует | Создать нейтральный project по согласованному шаблону: без `lessons`, планы в `docs/plans`. |
| common-only, project уже существует | Сохранить полезные файлы и legacy `lessons`; не дополнять автоматически новым каркасом. |
| common+project | Сохранить существующий project побайтно; небезопасные или отсутствующие обязательные ресурсы должны приводить к отказу проверки. |
