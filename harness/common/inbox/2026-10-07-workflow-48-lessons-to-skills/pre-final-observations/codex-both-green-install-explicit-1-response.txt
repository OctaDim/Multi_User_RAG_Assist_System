| Режим | Требуемое поведение |
|---|---|
| common-only, project отсутствует | Создать нейтральный project из явного `project-skeleton.json`: без `lessons`, планы в `docs/plans`, без материалов прежнего проекта. |
| common-only, project существует | Сохранить существующий project; не заменять и не дополнять автоматически по новой редакции шаблона. |
| common+project | Сохранить project побайтно, включая legacy `lessons` и полезные файлы. Отсутствующие или небезопасные обязательные ресурсы должны вызвать отказ. |
