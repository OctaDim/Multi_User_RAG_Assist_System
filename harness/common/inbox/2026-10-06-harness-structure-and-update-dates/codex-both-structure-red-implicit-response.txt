Два режима установки:

- **Только common:** проверка создаёт отсутствующий нейтральный project из `harness/common/base/project-skeleton.json`, включая десять категорий и INDEX/START; материалы прежнего проекта не переносятся.
- **Common+project:** существующие проектные файлы сохраняются побайтно; новая редакция шаблона автоматически их не дополняет.
- **Project-only:** диагностируемый отказ, негативный контроль. Старый project entrypoint допустим только как вызов common для совместимости.
