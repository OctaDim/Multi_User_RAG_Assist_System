# Скиллы Claude Code в проекте

Полные обычные установочные копии скиллов для Claude Code. Общие версии происходят из harness; при личном режиме копируется соответствующая папка из .agents/skills/.

Пример: comm-create-lazy-claude-codex-skills/ имеет тот же комплект SKILL.md и ресурсов, что общий источник и копия для Codex.

Равенство состава и байтов позволяет обнаружить рассинхрон. Оно не доказывает, что агент обнаружил скилл или правильно применил его.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
