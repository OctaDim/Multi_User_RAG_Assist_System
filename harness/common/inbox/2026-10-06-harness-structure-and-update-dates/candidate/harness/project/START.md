# Старт пакета EPL

Проектный пакет требует установленного harness/common/; отдельно не переносится. В обоих поддерживаемых режимах из корня проекта используется общая проверка:

```sh
python3 -B harness/common/checks/ensure_entrypoint_links.py
```

После команды статичного входа второй запуск не нужен. Старый проектный путь проверки сохраняется только как вызов common для совместимости прежних входов, а не автономная реализация. Затем ищи материалы EPL по категориям INDEX.md; подробности открывай по задаче.
