# Независимая проверка входов трёх режимов

Дата: 2026-10-05. Область: стартовая проверка и ссылки пакетов, не полнота всего harness.

## Согласованное изменение

Пользователь выбрал вариант 1: обычная установочная копия технического скрипта в project/checks; исходник common/checks. Документы и знания не дублируются. Проектная копия исполняется самостоятельно, без чтения common. В совместной установке сравниваются байты.

Новый согласованный статичный вход выбирает команду существующего пакета: common при его наличии, иначе project. Остальные настройки существующего AGENTS.md не переписываются. Предупреждение о договорённости и сообщение до восстановления сохранены; hooks, индивидуальные настройки и Git не обязательны.

## RED → GREEN

`python3 -B harness/common/checks/test_entrypoint_portability.py`

- До установочной копии: 3 ожидаемых падения — отсутствующий скрипт project, отсутствие независимого запуска и ресурса для проверки повреждения.
- После одного копирования, до исправления шаблона: осталось 1 падение. Сгенерированная стартовая команда project-only ссылалась на отсутствующий common.
- После выбора команды по установленным пакетам: 4 теста, OK. Проверяются реальный запуск сгенерированной команды, идемпотентность, сохранность существующих настроек, отсутствие Git/индивидуальных настроек, обнаружение отсутствующего START.md и равенство обычных копий.

Прежние тесты: 7 тестов ссылок и 6 тестов предупреждений, OK. Всего в проверяемом дереве 17 тестов. При отдельном common новый тест проверяет только доступный пакет; остальные режимы и сравнение со второй копией прямо помечаются непроверенными. Отсутствующий обязательный скрипт установленного пакета не фильтруется и даёт ошибку.

## Проверка с изоляцией файловой системы

Использован установленный в среде диагностики bubblewrap. Он не становится зависимостью harness и не настраивает машину пользователя. Первая проба с --unshare-all отказала при NETLINK_ROUTE; проба с отдельными user/pid namespaces прошла. Файловая изоляция выполнялась без отдельной network namespace; проверяемый скрипт не делает сетевых вызовов.

Для каждого режима создан новый временный проект и скопированы только выбранные папки. В дочернем процессе смонтированы readonly /usr, библиотечные symlinks, собственные proc/dev и единственная рабочая папка /workspace. Исходные /home и /tmp не смонтированы. Запуск Python -I -B, PATH не содержит Git. Внутри процесса попытки открыть AGENTS.md EPL, AGENTS.md исходного GLOBAL_HARNESS_ENVIRONMENT, исходный staging-скрипт и глобальную конфигурацию автора не прошли. Отсутствующий сосед также недоступен.

Проверены два реальных запуска: создание согласованного входа собственной копией и выполнение команды, записанной в новом AGENTS.md. Второй запуск не меняет байты и не сообщает о повреждении. Далее удаляется обязательный START.md; собственная проверка сообщает об отсутствии ресурса и завершается кодом 2, не изменяя входы.

| Режим | Создание входа | Команда входа | Повреждённый START | Доступ к исходникам |
|---|---:|---:|---:|---|
| Только common | 0 | 0 | 2 | Недоступен |
| Только project | 0 | 0 | 2 | Недоступен |
| Оба пакета | 0 | 0 | 2 | Недоступен |

В тех же изолированных копиях проверяются локальные Markdown-ссылки внутри границы каждой папки. README.human.md исключён до чтения содержимого. Внешние URL не проверяются этим прогоном.

## Границы результата

Подтверждена автономность конкретной проверки входов и доступность проверенных Markdown-ресурсов. Это не аудит всех команд, всех будущих ресурсов, поведения приложения EPL, полный перенос знаний или нативное обнаружение Codex/Claude. Нативные агенты не запускались этим тестом. Стартовый токен-бюджет и подключение всех правил/скиллов остаются непроверенными.

Обязательная команда существующего пользовательского AGENTS.md не изменяется при удалении пакета. Если пользователь переносит старый корневой вход с командой удалённого common, изменение команды требует согласованной заявки в inbox. Автоматически исправляется только создание нового согласованного входа и восстановление ссылок.

После обновления документов изолированный прогон повторён: common — 51 локальная
ссылка, project — 10, оба — 61. Все положительные команды: exit 0; все удаления
обязательного START.md: exit 2. Runtime-копии совпадают побайтно.

Generic Plugin Eval двух изменённых правил: статическая оценка уменьшена с 757
до 629 токенов, 0 fail / 0 warn. Сохранены пять исходных структурных требований и
узкое согласованное исключение. Это не специализированная приёмка SKILL.md/плагина
и не живое измерение контекста; observed usage отсутствует.

Финальный повтор использовал опубликованные папки GLOBAL_HARNESS_ENVIRONMENT,
а не staging. В файловой изоляции common-only и оба пакета дополнительно прошли
все три файла тестов (4 + 7 + 6); project-only прошёл свою стартовую команду
и отрицательную проверку ресурса без common. Локальные ссылки: 51 / 10 / 61.
Корневые AGENTS.md и CLAUDE.md в исходном проекте сохранены без изменения байтов.
