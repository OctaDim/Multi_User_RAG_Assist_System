# Миграция структуры harness

Дата создания: 2026-10-06. Стадия: окончательный кандидат; публикация ожидает
разрешения на текущую версию с непроверенным Claude.

Оба пакета имеют 12 категорий и testing/acceptance, tests, evidence.
Каркас явно сохранён в base/project-skeleton.json. Классификация и постоянные
даты создания закреплены в specs/2026-10-06-structure-and-creation-dates.md.
Пользователь отдельно разрешил каркас, подтвердил пользу папок для всех
проектов и подтвердил адресную таблицу дат 48 старых материалов.

Пять основных pytest-модулей перенесены из checks в testing/tests;
acceptance — в testing/acceptance; launcher и общий runner — в scripts.
Технические manifests/config сохраняют стабильные имена. Документы и знания
получили подтверждённые префиксы дат. Связанные MD/JSON собраны в предметные
папки; дата новой папки независима от вложенных файлов и не меняется при правках.
Автоматического обслуживания дат нет. Старые inbox-снимки не перестраивались.

## Сохранность и проверки

[Карта](2026-10-06-migration-map.json) охватывает 79 исходных ресурсов с прежними
и текущими hashes. Все исторические raw JSON сохранены побайтово.
[Оригинальные Markdown и программы](2026-10-06-originals.json) сохранены как
данные для сверки; команды, результаты и прежние hashes не объявлены новым
прогоном. Рабочие Markdown-ссылки пересчитаны; исходная ошибка одной ссылки
исправлена. [Аудит](2026-10-06-candidate-audit.json): 194 ссылок, включая
27 исторических ссылок в inbox, разрешённых в исходном проекте. Такие ссылки
обозначают происхождение, а не обязательные ресурсы переносимого пакета.

Все семь фактических тестовых редакций, включая новый кандидат и прежние
копии inbox, прошли: 239 случаев. Основной набор — 57. Production checker,
legacy shim и Node.js launcher сохранили байты; тесты изменены только для новых
путей и согласованного каркаса. AGENTS.md/CLAUDE.md сохранены побайтово.

[Чистые установки](2026-10-06-clean-portability.json) используют отдельные
uv-окружения из существующего lock, с исходным проектом и глобальными
инструкциями автора, скрытыми через bwrap. Common-only: 55 PASS + два прежних
SKIP отсутствующего legacy shim; common+project: 57 PASS. Старт работает
до установки pytest. Отказ project-only, сохранение существующего project,
повторный запуск, повреждение обязательных ресурсов и небезопасные пути
покрыты успешными тестами. Reviewer отдельно проверил sparse project без
новых категорий: обычный старт их не добавляет и сохраняет байты/mtime.

Независимый reviewer проверил карту, даты, сохранность, ссылки, копии,
discovery и установку; найденные изменения кандидатного AGENTS.md,
human README в нативном rules и неправильный путь runner исправлены.
Reviewer ошибочно прочитал human README через wildcard в раннем проходе;
это не засчитано как успешная проверка исключения человеческого контента.
Финальные правки скилла проверены явно названными файлами.

## Нативное поведение и компактность

[RED](2026-10-06-red-observations.json): в обоих режимах исходные инструкции
направляли launcher/тесты/отчёты в checks, не требовали правильного именования
и допускали wildcard-чтение human README. Первая попытка GREEN исправила
структуру, но два неявных вызова прочитали human canary. Эти попытки сохранены
отдельно и не выдаются за успех. Указание читать только явно названные машинные
ресурсы поднято перед чтением ресурсов в скилле; обязательный контракт сохранён.

[Финальный GREEN r2](2026-10-06-final-native-observations.json): все четыре
сценария PASS — common-only/common+project, explicit/implicit. Нативный каталог
предоставил скилл, он выбран, собственные SKILL/validation и новая спецификация
прочитаны; фактический текст совпал с финальными файлами. Наблюдались новые
пути, постоянные даты, согласование неизвестных дат и gate публикации;
канарейки человеческих README не попали в вывод, записей не было.
[Два коротких сценария согласования](2026-10-06-permission-guard.json) с разрешённой
записью в изолированный fixture остановились с конкретным вопросом создания/
выполнения inbox до сохранения урока; файловых изменений нет.

quick_validate.py PASS. Полные обычные копии скилла, включая hashes human
guides без вывода их тел, совпали с источником; шесть обычных копий правил равны.
[Анализ скилла](2026-10-06-skill-final-analysis.json): 95/A, без FAIL,
с предупреждением deferred budget. Отдельные generic-анализы правил — 95–100/A,
без FAIL; generic-анализ не заменяет нативные сценарии. Совместная оценка шести
правил — 86/B из-за суммарного бюджета; это оценка общего стартового объёма,
не дефект отдельного артефакта. Предупреждения сохранены, не скрыты изменением
порогов. Все оценки токенов статические и не являются измеренным расходом сессии.

Codex — проверено в области этой миграции, её путей, ресурсов, сценариев
размещения/дат и сохранения согласований. Прежние результаты других версий
и непрогонявшихся сценариев этим не повышаются. Claude — непроверенный,
не запускался. Итоговый статус — непроверенный. Это не полная двусторонняя
приёмка. Публикация текущих канонических инструкций и нативных копий требует
отдельного явного разрешения и подтверждения на указанных условиях.

Сырые потоки всех нативных попыток сохранены без потерь в gzip-архивах с
[hashes исходного JSON/ответов](2026-10-06-native-archive-manifest.json).
Ошибка ранних попыток могла включить человеческое тело в поток; архивы нельзя
разворачивать в агентский контекст. Для проверки использовать программные
наблюдения без вывода человеческих тел. Декомпрессия сохраняет исходные байты.
