# Установка зависимостей через uv

До выбора процедуры установки рабочих, тестовых или инструментальных зависимостей,
в том числе для проверок и скиллов, применяй `uv` в common и project.

- Python: используй существующий режим проекта — `uv sync`/`uv add`,
  `uv pip install`/`uv pip sync` для отдельного окружения или `uv tool install`
  для инструмента. Сохраняй ограничения версий, источники и изоляцию;
  не меняй формат проекта ради установщика.
- Если `uv` отсутствует или установка неуспешна, сообщи конкретное препятствие
  и останови зависимую установку. Не переходи самостоятельно на `pip`,
  `python -m pip`, `pipx`, Poetry или иной установщик. Подготовка самого `uv`
  согласуется отдельно и не разрешает замену способа установки зависимостей.
- Для системных, Node.js и других зависимостей, которые `uv` не устанавливает,
  объясни конкретную границу, предложи способ и получи явное решение пользователя
  до установки. `uv run npm install` не считается установкой посредством `uv`.

Соблюдение: Python-зависимости установлены через `uv` с прежними ограничениями;
недоступность и неподдерживаемые типы не приводят к автоматическому обходу.
