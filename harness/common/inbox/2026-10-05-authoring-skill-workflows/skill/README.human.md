# Кандидаты скиллов заявки

Часть заявки «Расширение процедуры авторства»: `skill/`. Это кандидат скилла данной заявки. Это временные материалы внутри inbox, а не установленный пакет. Каталог содержит подпапки комплекта.

Пример: `comm-create-lazy-claude-codex-skills/` — существующая подпапка с материалами этой части комплекта.

Подпапка помогает воспроизвести структуру сохранённого комплекта; она не означает, что весь пакет установлен или полностью проверен.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
