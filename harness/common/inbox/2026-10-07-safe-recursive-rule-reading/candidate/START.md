# Обязательные границы

После стартовой проверки прочитай `rules/comm-skill-rule-ownership.md` до выбора
процедуры. AGENTS.md/CLAUDE.md напрямую не редактировать; согласованное создание
и восстановление стартовых ссылок — узкое исключение. Динамическая память — harness.

Перед перечислением всех правил прочитай `rules/comm-human-folder-guides.md`:
там способ получить полный список машинных файлов и безопасно прочитать их.

После START обоих пакетов прочитай все установленные правила полными
завершёнными вызовами. Не объединяй правила и тело скилла либо его ресурсы
в одном вызове; сначала получи результаты чтения правил, затем открывай скилл.
Правила задают короткие границы и когда открыть скилл.
Тела скиллов и ресурсы загружай только для соответствующего действия;
обычный старт не является задачей установки или авторства. INDEX — карта категорий.
