# Сократить правило человеческих пояснений без потери поведения

Дата создания: 2026-10-06.

## Контекст

- Когда возникла потребность: 2026-10-06, после обсуждения стоимости загрузки запрета чтения README.human.md и возможности сокращения правила.
- Обстоятельства: правило `.claude/rules/comm-human-folder-guides.md` читается на старте; текущий текст содержит 1621 символ (2880 байт) и регулирует не только запрет чтения, но и создание пояснений и допустимые программные проверки.
- Причина: часть формулировок можно объединить, уменьшив постоянный контекст без удаления обязательных требований.
- Что решит выполнение: снизит объём правила при сохранении области применения, поведения и ограничений.
- Требуемый результат: проверить сокращённый вариант, затем по действующему gate обновить [канонический источник](../../rules/comm-human-folder-guides.md) и одинаковую [нативную копию](../../../../.claude/rules/comm-human-folder-guides.md). Не менять остальные правила или защищённые входы.

## Предложенный вариант

Это ранее подготовленный текстовый кандидат: 1137 символов (2025 байт), сокращение по символам — 29,9%. Это сравнение размеров файлов, не измерение расхода токенов. Поведенческая эквивалентность у Codex и Claude не подтверждена.

```markdown
# Человеческие пояснения harness

При создании категорий/подпапок harness, подключении контекста или поиске знаний:

- Создавай согласованную структуру заранее, даже пустые категории. Каждой папке harness, включая корни пакетов, нужен README.human.md; новой подпапке — сразу. Просто объясни назначение и материалы, дай наглядный пример с пояснением; для пустой категории отметь иллюстративность примера. README не подтверждает наполненность или проверенность.
- Эти файлы — только для человека, не источник правил; агентские инструкции храни отдельно. Не читай тела и не загружай в контекст при старте, маршрутизации, поиске или сборке материалов. Исключай из агентских индексов, импортов, описаний скиллов, стартовых инструкций, общего cat и сборщиков контекста; при поиске используй -g '!README.human.md'.
- Программная проверка наличия/структуры может читать файлы, возвращая агенту только результат, пути и ошибки. Создание пояснения не требует чтения других.
- Отдельно проверяй чтение правила, исключение файлов из загрузчиков и поведение агентов. Инструкция не блокирует файловый доступ и не доказывает технический запрет чтения.
```

## При последующей обработке

Сверить все требования исходного правила с кандидатом и выполнить применимые проверки итоговой версии. Реальные нативные проверки Codex и Claude учитывать отдельно; отсутствие выполненного прогона не выдавать за техническую недоступность. Подтверждённые препятствия фиксировать с причиной. Подагенты разрешены пользователем при необходимости, но не обязательны для обычного запуска CLI.

Без полной проверки не устанавливать новую версию без явного разрешения на непроверенную публикацию. Доказательства выполненной обработки сохранять вне временного inbox по контракту harness.
