# Интерфейс корпоративной базы знаний RAG

Основной экран — беседа в центре. Кнопка «Основания» открывает панель рядом с перепиской; на узком экране она занимает рабочую область, а «Закрыть» возвращает беседу. Действие «Показать основания» у ответа выбирает именно его сохранённые фрагменты и паспорт. Ссылка цитаты переводит фокус на исходный фрагмент. На узком экране индикатор «новые» сообщает о появлении оснований, пока панель закрыта.

«Мои беседы» показывает различимые названия по первому вопросу. Список бесед и выбор источников свернуты при входе и во время ввода, чтобы оставить место переписке. Они раскрываются по одному, а длинные списки прокручиваются в своей области. Заголовок источников всегда показывает режим поиска или число выбранных документов. Текст вопроса и выбор источников принадлежат каждой беседе и вкладке. Переходы по разделам и перезагрузка сохраняют черновик; выход, смена пользователя и закрытие вкладки очищают его по существующему контракту. Раздел после перезагрузки восстанавливается; новый вход открывает беседу.

Если ни один источник не отмечен, поиск использует все готовые доступные документы пользователя. Отметки ограничивают поиск выбранными документами. Исчезновение выбранного источника не включает поиск по всей библиотеке: недоступный выбор остаётся видимым до явного снятия. При приёме вопроса сервер фиксирует состав документов; новые документы входят в следующий вопрос. Рядом с полем вопроса показана причина недоступности отправки. При неопределённом результате отправки предусмотрена проверка той же операции, без автоматической новой генерации.

«Документы» объединяет загрузку, обработку, выбор режима OCR, отчёт об ошибке, оригинал, исправление текста и удаление. Обновление статусов сохраняет редактор. Если документ удалён в другой вкладке, несохранённый текст остаётся доступен для копирования, а сохранение в удалённый источник блокируется. Закрытие с несохранённым текстом требует решения; удаление показывает название и последствия и допускает отмену. Сохранённое исправление может ожидать публикации: это состояние отображается отдельно, повторное сохранение до публикации недоступно. После сетевой ошибки загрузки сначала обновите список и проверьте результат, затем при необходимости выберите файл заново.

«Управление» доступно администраторам в пределах роли. Оно содержит аккаунты, индивидуальные ограничения документов и, для суперадминистратора, глобальные настройки генерации с предпросмотром и сохранённой/применённой ревизиями. Чужая библиотека явно подписана, доступна для чтения и имеет возврат к своей. Её просмотр не меняет источники вопроса.

Кнопки и формы показывают выполнение и ошибки рядом с действием. Ошибка отправки видна у поля вопроса и относится к соответствующей беседе; переход в другую беседу не переносит её туда. Правка вопроса или новый выбор источников снимает прежнее сообщение. После отказа открытия можно повторить выбор беседы; при неизвестном результате создания обновите страницу и проверьте список перед повтором. При временном отказе публичной политики доступно «Повторить подключение», при ошибке остановки — повтор остановки. Общий таймаут API настраивается через `client.request_timeout_ms` в конфигурации фронта; поток событий сохраняет отдельный механизм восстановления соединения.

Приложение по-прежнему запускается через `python3 backend/main.py` и `python3 frontend/main.py`. Новые зависимости и сборщик JavaScript не нужны. Параметры установки описаны в [настройках приложения](2026-10-16-application-settings.md).
