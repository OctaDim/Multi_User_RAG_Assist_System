# RAG-67: допуски OCR по фактическому типу каждого слова и конкретной модели

Окончательное уточнение пользователя от 2026-10-14. Действующий контракт заменяет несовместимые допуски [RAG-65](2026-10-14-belarusian-ocr-model-specific-tolerances.md) и [RAG-66](2026-10-14-ocr-source-types-and-future-model-permissions.md). Исторические решения, эталоны и результаты остаются сохранёнными; они не подтверждают приёмку по новому контракту.

## Решение пользователя

**По умолчанию ошибки запрещены. Допуск определяется фактическим типом каждого слова и конкретной моделью OCR.**

| Модель и текст | Допуск |
| --- | --- |
| **Текущий PaddleOCR-VL 1.5 — печатный белорусский** | Только замены **«ў» → «у»** или её вариантов с надстрочными знаками и/или **«і/i» → варианты с надстрочными знаками**. Остальные ошибки запрещены. |
| **Текущий Qwen3.5-2B Q4_K_M + F16 — рукописный белорусский** | Ошибки распознавания белорусских слов допускаются. |
| **Будущая более мощная рукописная OCR-модель** | Ошибки рукописи запрещены без нового явного согласия пользователя. |
| **Будущая более мощная печатная OCR-модель** | Ошибки печатного текста запрещены без нового явного согласия пользователя. |

В смешанной области **каждое слово оценивается отдельно**: печатное получает только применимый печатный допуск, рукописное — только применимый рукописный. Общая рамка, один OCR-кроп или выбор распознавателя не меняют фактический тип слова и не переносят допуск между типами.

Новые модели не наследуют исключения автоматически. Основной печатный OCR — **Paddle**, рукописный — **Qwen**.

Сырые результаты и эталоны сохраняются; разрешённые расхождения явно отмечаются без скрытого исправления.

## Применение контракта

- Общий допуск ошибок текущего Paddle из RAG-65/RAG-66 больше не действует. Печатные белорусские слова допускают только перечисленные символьные замены при распознавании текущим PaddleOCR-VL 1.5. Другие буквы, слова, пропуски, добавления и изменения дат не получают исключения.
- Печатный допуск текущего Qwen из RAG-66 больше не действует. Печатные слова, распознанные Qwen, оцениваются по правилу запрета ошибок. Рукописные слова, распознанные Paddle, также не получают перечисленного печатного допуска.
- Рукописное исключение действует только для белорусских исходных рукописных слов и закреплённого Qwen3.5-2B Q4_K_M с F16-проектором. Оно не распространяется на печатные слова внутри того же изображения или кропа.
- Применимость исключения проверяется по фактическому исходному слову и идентичности модели вместе с проектором, закреплённым версией и контрольными суммами в текущем OCR-профиле. Метка области, языка или выбранного распознавателя сама по себе недостаточна.
- Для иной модели действует запрет ошибок, пока пользователь явно не разрешит конкретное исключение. Будущая замена модели не наследует допуски даже при совпадении семейства или назначения.
- Приёмка сохраняет исходные эталоны и сырую транскрипцию, отдельно отмечает точные совпадения и каждое разрешённое расхождение. Допуск не вводит исправление результата модели в рабочем OCR-конвейере.

Роли моделей из [RAG-64](2026-10-14-printed-and-handwritten-ocr-models-contract.md) сохраняются. Не меняются требования к маскированию запрещённой рукописи до печатного OCR, сохранности оригиналов, изоляции пользователей и целостной публикации документов. Допуски OCR не разрешают ошибки ответов или цитат в закреплённых 30 контрольных вопросах RAG.

После каждого этапа U выполняются все накопленные регрессионные тесты приложения и все активные тесты harness без исключений. Результаты старых прогонов сохраняются с действовавшим тогда контрактом; окончательная приёмка должна проверять RAG-67.
