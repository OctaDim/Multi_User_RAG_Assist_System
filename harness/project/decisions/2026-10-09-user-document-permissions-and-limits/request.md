## Согласованные требования

- OCR рукописей входит в MVP вместе с печатным текстом в PDF. Сохраняются
  ранее согласованные русский, белорусский, английский и немецкий языки.
- Для каждого пользователя нужны отдельные поля разрешений загрузки PDF,
  DOCX, TXT, Markdown и разрешения OCR рукописей. Право на рукописи не заменяет
  разрешение формата исходного файла. Требования применяются на backend.
- Все пять лимитов RAG-13 задаются отдельно для каждого пользователя.
  Начальные значения остаются дефолтами: 50 МБ/файл, 500 страниц/PDF,
  20 файлов/загрузка, 1000 документов и 2 ГБ оригиналов/пользователь.
- Разрешения и персональные лимиты нужны для раздельной тарификации в будущем.
  Тарифы, платёжный провайдер и биллинг не утверждаются; paid в MVP не проверяется.
- Глобальные динамические настройки и лимиты через админку изменяет только
  super_admin. Обычный admin не может менять их, но может менять лимиты отдельных
  пользователей. Прежний запрет admin на чтение чужих документов/переписок сохраняется.
- Точные имена полей, значения разрешений по умолчанию, права изменения разрешений форматов/OCR,
  связь с будущими тарифами и применение новых персональных лимитов во время
  незавершённых операций определяются при техническом проектировании.
- Качество OCR рукописей и совокупная нагрузка пока не проверены.
