# Приём вопросов и сохранение истории

Здесь сохраняются результаты этапа U2: настоящие транзакции PostgreSQL,
повторные запросы и сохранение настроек. Например, admission-red-v1.txt содержит
первую проверку до реализации, а admission-green-v1.txt — проверку готового кода.
Фикстуры аккаунтов и документов не заменяют проверку их реальных компонентов.
