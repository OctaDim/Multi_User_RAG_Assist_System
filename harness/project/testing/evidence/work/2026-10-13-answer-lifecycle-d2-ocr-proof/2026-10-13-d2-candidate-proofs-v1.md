# D2 candidate proofs — publisher gate remains open

These are independent technical preparations for real G4, not application regression or U completion. No production OCR dependency/engine/publisher was installed. Temporary Python environment contains Pillow12.3.0 and pypdfium2 5.14.0; actual native runtime is the existing llama-cpp-python0.3.36 CPU MTMD implementation. Model files/revisions/hash measurements are in downloaded-assets-v1.json. Every owned model probe finished and was reaped before D1 full native regression began.

Official PaddleOCR-VL-1.5 GGUF + mmproj loaded successfully. Native-ocr-v1.log preserves an initial Python API usage error (Llama has no context manager); corrected v2 uses explicit finally close. On a synthetic printed raster fixture, all five lines matched exactly: title plus budget sentences in English, German, Russian, Belarusian. The input is not real handwriting and is not a publisher proof. The output finished at EOS, not token truncation. Total wall90.24s, peakRSS3642576KiB. Native performance reports1267 actual prompt tokens including image embeddings; high-level usage51 excludes image embeddings and is not a valid context occupancy count. Printed fixture PDF preserves the original raster.

A real English handwriting image was obtained from the official PaddlePaddle PP-OCRv5_Online_Demo examples at an exact revision/hash in handwriting-source-v1.json. This is an author's published demo, not held-out handwriting or a guarantee for other languages. No poem transcription was performed; selected classifier regions were title/author/signature. Attempts to retrieve a US public archive PDF received HTTP403; no archive original is claimed.

The monkt/doctype ONNX classifier has NHWC float input1x320x320x3 and seven labels, whose ordering was checked from the associated dataset ClassLabel metadata. Whole-page characterization: 0–255 inputs degenerated to photo; 0–1 inputs classified the two examples printed0.98585/handwritten0.97279. This is empirical scaling evidence on two images only; model documentation does not specify preprocessing.

**Region separation proof failed.** In doctype-region-characterization-v1.json the cropped printed block was classified diagram0.9896 (stretch) or handwritten0.9504 (letterbox); the handwritten signature was photo0.9947 (stretch) or diagram0.8078 (letterbox). A handwritten title also became diagram0.9957 when stretched. Thus this page classifier is not accepted as a mixed-page printed/handwritten region detector. Automatic localization, permitted recognition-only crops, whole-file publication and RAG-61 skip mode remain unproved. No fallback that OCRs forbidden handwriting then hides it was built. No arbitrary page/request cap or quality threshold was added.
