# Проверка диалогов и выбранного оформления

Дата создания: 2026-10-20. Статус: завершено. Область: изменения приложения; это не свидетельство проверки механизма harness.

Основание и решения: [проектная запись](../../../docs/2026-10-20-dialog-management-and-design.md). Пользователь выбрал P1 и E1; исходный вариант A, высота истории 10× и прокрутка к новым сообщениям сохранены. [Макет вариантов](../../../docs/2026-10-20-dialog-interface-options.html) содержит только демонстрационные данные и действия.

## Результат

| Требование | Проверка |
|---|---|
| Удаление, подтверждение, hover, дата/время, плотный список | Реальные регистрация, API и браузер; отмена сохраняет строку, подтверждение убирает на двух вкладках и после reload |
| Ошибка удаления | HTTP 503 сохраняет историю и черновик; повтор с настоящим API удаляет |
| Видимая полоса прокрутки | 18 диалогов через реальный API, начало/конец списка на 1440×1000 и 375×812; меню остаётся в экране; заголовок закреплён |
| Очередь файлов | Исключённый файл не присутствует в POST; загружается оставшийся; после успеха очередь пустая; нет горизонтального переполнения 1440/768/375 |
| История 10× и автопрокрутка | Браузерная геометрия и production renderer; синтетическое содержимое изолирует прокрутку, не выдаётся за ответ модели |
| Владение и удалённые записи | Чужие admin/super_admin получают 404; удаление идемпотентно; активный запрос блокирует удаление; документы сохраняются; старые снимки/события не восстанавливают историю |
| Даты и миграция | 0007→0008 сохраняет записи и неизвестные даты NULL; новые даты реальны; обновление после stop меняется; конкурентная запись не повышает разделяемую блокировку |
| Реальная LLM/RAG | Ответ без документов и сохранение контекста, поиск по всем готовым источникам, цитаты старого ответа и переходы между областями |

## Итоговые запуски

Команда-обёртка: `backend/.venv/bin/python /tmp/run-rag-front-tests.py -c backend/pyproject.toml … -q --tb=short --show-capture=no --junitxml=…`. Она использует модели из действующей конфигурации, изолированную PostgreSQL и локальную тестовую почту/API. Тестовая БД не переносилась в рабочую конфигурацию.

- [UI 10](2026-10-20-dialogs-ui-10.xml): **13 passed**, один намеренно исключённый здесь native-сценарий проверен отдельно. Для настоящего вида полос отключён стандартный флаг Playwright `--hide-scrollbars`.
- [Core 06](2026-10-20-dialogs-core-06.xml): 166 passed / 3 failed. Порядок снимков исправлен; ожидания дополнены проверенными полями дат. Два тайминговых падения при одновременной нагрузке повторены отдельно. [Recheck 09](2026-10-20-dialogs-core-recheck-09.xml): **все три passed**. Единый новый зелёный прогон всех 169 не заявляется.
- [Focused 04](2026-10-20-dialogs-focused-04.xml): **15 passed**, в том числе воспроизведение конкуренции двух записывающих транзакций.
- [Native 05](2026-10-20-dialogs-native-05.xml): два native-сценария passed; третий завершил работу с ответами, но обнаружил горизонтальное переполнение файлового input. Исправлена ширина скрытого input.
- [Native final 11](2026-10-20-dialogs-native-final-11.xml): оставшийся сценарий цитат и навигации **passed** при последовательном запуске; [исходный лог](2026-10-20-dialogs-native-final-11.log).
- [Core 01](2026-10-20-dialogs-core-01.xml): 59 passed; [acceptance 01](2026-10-20-dialogs-acceptance-01.xml): 62 passed / ошибка подготовки длинного списка. Последующие новые проверки и исправления отражены выше.
- Проверка whitespace исходников, синтаксическая проверка изменённых JS и импортируемого Python — успешно. Полный staged `diff --check` отмечает только исходные пробелы в сохранённых сырых логах/XML; они намеренно не нормализованы, чтобы сохранить оригиналы свидетельств.
- Отдельный reviewer `/root/review_dialog_management` проверил реализацию и не сообщил существенных замечаний. Он не запускал тесты; это ревью кода, а не независимое подтверждение тестовых результатов.

## Промежуточные неуспешные результаты

[RED 01](2026-10-20-dialogs-red-01.xml): пять ожидаемых падений до реализации и один пройденный сценарий очереди. [Browser 01](2026-10-20-dialogs-browser-01.xml) сохраняет ошибку готовности генератора и незавершившиеся основания. [Regression 02](2026-10-20-dialogs-regression-02.xml) не запустил тесты из-за неверного имени модуля.

[Regression 03](2026-10-20-dialogs-regression-03.xml) выявил переполнение меню, измерение высоты и зависшую генерацию. В диагностическом выводе исходного временного generation.log наблюдался `DeadlockDetected`: запись даты повышала блокировку диалога после захвата запроса. Исправлено получением блокировки диалога на запись до запроса в координаторе и saver. Старый временный лог уже отсутствовал после последующих запусков pytest; полный исходник не заявляется сохранённым и не восстанавливался искусственно.

[Scroll 01](2026-10-20-dialog-scroll-01.xml) выявил неучтённую высоту сообщения статуса; [Scroll 02](2026-10-20-dialog-scroll-02.xml) — позднее снятие высоты истории при переходе в документы. Исправлены расчёт доступной высоты и синхронное снятие расширения при смене области. [UI 07](2026-10-20-dialogs-ui-07.xml) выявил гонку синтетической истории с первым настоящим heartbeat: тест теперь сначала ждёт соединения. [Native citations 08](2026-10-20-dialogs-native-citations-08.xml) не уложился в 30 с при совместной нагрузке; последовательный final 11 прошёл без изменения рабочего таймаута/guards модели.

Все исходные сохранённые XML/снимки остаются отдельными файлами, не переписаны итоговыми успехами.

## Обычный запуск

`python3 backend/main.py` из корня проекта; конфигурация и модельные пути действующие, без тестовых переменных. [Проверка startup 12](2026-10-20-dialogs-startup-12.json): версия 0007→0008; **16 диалогов и 5 документов сохранены**; public-settings/frontend HTTP 200; новый DELETE зарегистрирован и без входа отвечает 401; epoch 14, здоровый lease подтверждён повторно через 5 с. Это наблюдение запуска, а не обещание бессрочной доступности.

Рабочий frontend: `http://127.0.0.1:55848/`. Открытие вкладки инструментом имеет статус queued и не считается подтверждением просмотра.
