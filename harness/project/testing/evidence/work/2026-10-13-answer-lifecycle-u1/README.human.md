# Проверки первого этапа реализации RAG

Здесь сохраняются исходные результаты проверок U1 и отчёт о фактическом состоянии
плана жизненного цикла ответа. Например, browser-proof-v1.txt показывает, что
произошло с черновиком при обновлении и восстановлении закрытой вкладки.
Непройденная проверка не означает, что приложение уже реализовано.
