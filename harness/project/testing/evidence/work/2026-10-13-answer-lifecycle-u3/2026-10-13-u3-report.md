## U4 integration interface

Construct/cache `E5Embedder(os.environ['RAG_E5_DIR'])` once in the coordinator. `encode(texts, query=False)` returns passage vectors; queries use `query=True`. It loads existing local model_quantized.onnx and tokenizer.json, ONNX Runtime CPU only, truncating E5 inputs to its 512-token model limit. There is no download/provider/fallback code.

Call `run_graph(pool, request_id, execution_epoch, embedder, tokenize, token=None, generate=None, min_similarity=0.75)`. `tokenize` receives the complete str prompt and returns actual token IDs from the coordinator's shared model vocabulary. The call claims one admitted graph execution; a duplicate start, terminal request, lost service epoch or invalid current access fails. Every fresh request uses a separate persisted thread string carrying conversation/request/context epoch. It never starts a new question from a former checkpoint or resumes a lost execution.

The returned state includes `prompt`, actual `tokens`, `response_tokens` (all remaining capacity, not a 256-token cap), `passport`, `fragments`, `history` and `dependencies`. Packing reserves at least 256 response tokens, discards oldest history pairs before lowest-ranked fragments, and rejects an oversized irreducible prompt. The thinking-off assistant tail is already included in the counted prompt; U4 must not append a separate uncounted tail.

Passport fields: selected document IDs, available document/revision/mode/limitations, excluded selected IDs, found fragment spans, actually passed fragment spans, insufficient_evidence, history_requests, and history_dependencies for source revisions of the history actually passed. `request_sources` stores all found early fragments plus passed historical provenance, transitively: early UI excerpts are used information even when prompt packing trims them. Citation evidence is limited to direct actually passed spans; `validate_citations(list_of_dicts, passport)` expects id, absolute start/end and exact quote and raises invalid_citation for an invented/mismatched span. U4/U6 still own parsing model output and invoking this validation before displaying model citations as evidence.

Optional async `generate(state)` runs as a real graph node after early fragments commit. Keep terminal DB transition after the graph's final saver writes; terminal saver operations are deliberately rejected. Prepare-only graph invocation is available for coordinator queuing, after which native generation can use returned state. `GuardedSaver(pool, binding, token=None)` supports aget_tuple/alist/aput/aput_writes, using owner/account access and request/service/conversation/account epochs within the same transaction as raw AsyncPostgresSaver operations. API users may additionally supply a session token; trusted coordinator calls do not store session secrets. Use graph_bindings plus this boundary, never expose a raw runtime saver.

`sources.change_source(connection, token, document_id, deleted=True)` or `revision_id=<complete published staged identity>` changes the source projection, marks affected source provenance and invalidates conversation epochs. OCR correction does not cancel a currently unfinished answer; late completion receives corrected-source labels through answers.transition(). An old graph epoch cannot write another checkpoint after correction, so U4/U7 must distinguish the denied stale checkpoint from the agreed native answer continuation. Deleted used sources take the common interrupted transition. This helper does not implement a transport barrier, native cancellation/reap or recovery.

## Boundaries and considered-not-built

G3 real account issuer, G4 real document/OCR uploader/publisher and G5 deployment remain open. Test principals and source projections are explicitly contract fixtures, not real integration. Real selected-model answer generation/citation extraction, scheduler/SSE/frontend/transport handoff barriers and native resource recovery belong to subsequent units and were not implemented here. No standalone summary cache was added: derived summaries in eligible history are governed by the same transitive provenance.

Search defaults (12 nearest fragments and cosine similarity 0.75) are local retrieval behavior, not a calibrated guarantee of semantic relevance or 30/30 QA acceptance. Such calibration remains real-document acceptance. The supported publication boundary requires a new revision identity for OCR changes and complete immutable data before switching the document pointer; direct publisher writes outside that contract are not integrated.
