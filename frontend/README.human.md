# Независимый веб-интерфейс

Статический интерфейс регистрации, подтверждения email, входа и управления аккаунтами.
Он обращается к backend только через HTTP API. Перед размещением укажите публичный
адрес API в meta `api-origin` файла index.html и тот же адрес frontend в
`RAG_FRONTEND_ORIGIN` backend. Например, локально frontend можно запустить
`python3 -m http.server 8999 --directory frontend`, а API — на порту 8000.
Для SMTP задайте RAG_SMTP_HOST, RAG_SMTP_PORT, RAG_SMTP_FROM; по умолчанию
используется STARTTLS. RAG_SMTP_SECURITY=plain разрешён только для собственного
локального тестового почтового сервера. Учётные SMTP данные остаются на backend.
Оператор создаёт одноразовое приглашение super_admin командой из backend
`python -m app.accounts --email operator@example.com`, затем открывает выданную
ссылку и проходит обычную регистрацию и подтверждение email.

Это первоначальный интерфейс аккаунтов D1. Ответы, документы и OCR добавляются
отдельными этапами. Он не означает завершения проверки всего приложения.
