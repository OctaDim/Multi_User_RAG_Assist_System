# Кандидат скилла подробного отчёта plugin-eval

Скилл объясняет размер каждого reference и остальных текстовых ресурсов,
когда оценка plugin-eval превышает порог или пользователь просит детализацию.
Например: SKILL.md=150/references/example.md=350 /Texts=500 --> 1000 (heavy-warn).
Папка содержит полный кандидат; нахождение здесь не означает установку.
