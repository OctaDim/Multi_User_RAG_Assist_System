# Скиллы Codex в проекте

Папки скиллов, доступных Codex через нативный проектный каталог. Общие comm-/proj- скиллы имеют источник в harness и обычные полные копии; индивидуальные скиллы могут иметь имена без префикса.

Пример: comm-create-lazy-claude-codex-skills/ соответствует общей процедуре из harness/common/skills/.

Общие материалы сохраняются видимыми Git. В личном режиме конкретные папки .agents/skills/ и их копии .claude/skills/ исключаются точными путями, а не исключением всего каталога.

Это пояснение для человека. При обычной работе агента его тело не входит в инструкции, поиск знаний или оценку скилла.
